# 地域活動スタート支援アプリ（仮称） — 現行設計 v3.0

> **2026-11-12更新／現在は設計のみ・アプリ未実装**

## このアプリは何をするもの？
**地域で非営利の活動を始めたい個人や立ち上げ前のチーム**が、やりたいことと準備状況を入力し、**「まず何をすればよいか」**を具体的に整理するWebアプリです。

### 利用者が得られるもの
- **準備の整理**：決まったこと、まだ未定なこと。
- **最初の一歩**：一人かチームか、協力者・責任者の状況に応じた具体的な行動と理由。
- **確認先への入口**：高岡市の市民活動相談や既存施設などの公式情報（利用可否は別確認）。
- **相談文の下書き**：伝える条件や質問をまとめ、確認してコピーできる（自動送信しない）。

**空き家は既存施設では活動条件を満たせない場合などに検討する選択肢の一つ**です。実物件の検索・所有者マッチングは初期MVPに含めません。

## 設計の現時点の限界
地域活動を始めたい個人・チームが**本当にこのアプリを求めているかは未検証**。公的アンケートで子どもの居場所の希望があっても、活動立ち上げ支援アプリの需要を直接示すものではありません。実装後、既存の自治体相談・検索・汎用AIとの比較を行って価値を確かめます。
