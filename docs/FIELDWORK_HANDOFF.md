# あなたにお願いしたい作業｜活動者向けMVPの需要検証 v2.0
更新：2026-11-12。**現地作業・協力依頼・実装は未実施**。

## いま最も優先すること（P0）
- [ ] **実際に活動を始めたい人・団体を3〜5組程度見つける**。単にアイデアを聞くのではなく、具体的な活動を始めようとして止まった経験がある人が望ましい。人数は探索の目安であり需要を証明しない。
- [ ] [活動者向けの聞き取り案](ACTIVITY_DISCOVERY_GUIDE.md)を読み、責任者・必要な承認・同意・記録の取扱いを確認する。
- [ ] 活動者が以前に使用した既存施設・検索・相談先・AIを確認して、**今回のアプリがなくても解決できるか**を聞く。
- [ ] チームで、主対象を活動希望者とする方針を共有。店舗/創業まで初期MVPに含めるか議論。

## 次にお願いしたいこと（P1）
- [ ] 高岡市の[公共施設CSV](https://www.city.takaoka.toyama.jp/material/files/group/4/20260401_sisetu.csv)を取得できたら添付。こちらの環境で実ファイルの全件検証は未完了。
- [ ] 候補となる地域交流施設の利用条件・活動対象・時間・予約制度を公式・管理者に確認（勝手に予約・協力済みと扱わない）。
- [ ] 子ども関連・飲食関連の活動の専門家確認や、運営を続ける人手の見込みを聞く。
- [ ] チームの人数・担当・作業時間を確定し、実装開始の判断を共有。

## あとでよいこと（P2）

- [ ] 空き家個別物件の所有者意思や賃貸・契約条件の確認。現MVPは物件検索をしない。
- [ ] Vercel/Cloudflareの実チーム運用検証（実装開始の承認後）。
