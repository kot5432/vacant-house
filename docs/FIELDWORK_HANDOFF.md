# あなたにお願いしたい作業｜実証準備ハンドオフ
更新：2026-11-12／現在は**設計・準備のみ**。外部への送信、現地調査、回答の収集、実装はまだしていない。

## まず最初にお願いしたい3つ（優先度P0）
- [ ] **P0-1：調査の責任者と管理方法を決める**。誰が調査の責任者か（学校の指導担当など、必要な承認先）、回答をどこに保存するか、誰が閲覧するか、いつ削除するか、問い合わせ先を決める。アンケートはそれまで**配布しない**。成果物：担当者と取扱ルールの確認メモ。
- [ ] **P0-2：調査協力をお願いできる先の候補を選ぶ**。博労・川原の地域交流センター、空き家活用推進協議会、地域の活動者などから候補2〜3先を検討。公開情報に記載があっても協力の約束ではない。成果物：依頼先候補と依頼方法のメモ。連絡は必要な承認・責任者決定後に行う。
- [ ] **P0-3：チームの作業体制を決める**。コンテスト応募メンバーは最大5人。チームの人数、担当（UI／診断／地域データ・調査）、週に使える時間、レビュー担当を確定。成果物：役割分担の表。

## 次に進めてもらいたいこと（優先度P1）
- [ ] **P1-1：公式CSVを取得して共有**。高岡市[公共施設CSV](https://www.city.takaoka.toyama.jp/material/files/group/4/20260401_sisetu.csv)を公式サイトから取得できる環境で保存。内容の改変・個人情報の追加をせず、このチャットへ添付または共有可能な場所へ置く。こちらではWeb閲覧・コンテナ接続制限により全行解析ができていない。成果物：元CSVファイル1件。実データを受け取れれば列・件数・欠損・座標・重複・利用可能な分類の監査ができる。
- [ ] **P1-2：アンケート予備確認を3〜5人へ実施**。調査責任者・取扱いを決め、[質問票案](QUESTIONNAIRE_DRAFT.md)を見せて「Q1地区」「Q4対象施設」「Q5希望とQ6利用意向」「Q7頻度」が理解できるか聞く。回答の実数集計に含めない。成果物：個人が識別できない改善点メモ。**回答の原文・個人情報は無断でChatGPTへ貼り付けない**。
- [ ] **P1-3：協力をお願いする**。必要な学校・団体の手続きを確認してから、候補団体へ調査趣旨と時間・利用方法を説明。断られた場合も問題なく、協力実績がない段階では応募資料に団体名を協力者として記載しない。成果物：協力の可否、受けられる質問の範囲（匿名の要点のみ）。
- [ ] **P1-4：所有者・地域利用者・専門家への聞き取りの可否を確認**。[聞き取り台本](INTERVIEW_SCRIPT.md)に従う。実在物件の詳しい住所・所有者氏名・連絡先はここに共有しない。成果物：匿名化した気付きと、説明を直すべき箇所。

## 時間に余裕があれば（優先度P2）
- [ ] **P2-1：既存施設の実際の利用制約を確認**。地域交流センターの貸出対象・利用可能時間・申請方法・満室状況の確認方法。公開ページの内容は参考になり、最新事情や予約可能状況は確認が必要。成果物：確認日・公式説明・不明点。
- [ ] **P2-2：地区データの境界資料を探す**。地区の境界GIS/公式区域定義が得られるか、市・公共GISへ問い合わせる。得られない場合はアプリの地区手動選択でよい。
- [ ] **P2-3：公開先のチーム試験**。実装開始の指示が出た後に、Vercel Hobbyのコミット作成者制約とGitHub PRプレビューを、実チームの権限で試す。難しければCloudflare Pagesへ変更。現時点では実施不要。

## 進捗を返してもらうときの書式（個人情報なし）
- 調査担当・承認の状態：「決定／相談中／未定」
- 公式CSV：「取得できた／できない」（取得できた場合はファイル添付）
- アンケート予備確認：「実施人数・不明瞭だった設問番号・改善要望の要約」
- 協力先：「候補の種類・確認できた範囲・次に確認したいこと」。相手の名前・連絡先は共有不要。
- 実装開始：「設計のまま／実装へ移行」の指示。**指示がない場合は設計と準備を維持する。**

## 補足
全部を一度にやる必要はない。**最初の一歩は「調査責任者を決める」と「CSVを取得する」**。CSVの監査は調査先の返信を待たずに進められる。調査ができなければ未調査と明示して基本診断を優先する。
