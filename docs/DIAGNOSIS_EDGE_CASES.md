# 活動・場所案内の境界条件 v2.0（設計のみ）
更新：2026-11-12／**期待値でありコード実行なし**。v1の建物3条件・A/B分類テストはGit履歴に保存。

| ID | 境界条件 | 期待する動作 |
| --- | --- | --- |
| E01 | 活動カテゴリ未選択 | エラーで次に進まない |
| E02 | activityId=other | 全場所タイプの汎用確認事項を表示 |
| E03 | 人数未入力または「不明」 | unknownとして扱い、人数の確認を促す |
| E04 | 人数0、負数、小数、非数値 | 入力エラー。「不明」へ勝手に変換しない |
| E05 | 人数1以上の整数 | 人数として保存。ただし施設の定員に適合と判定しない |
| E06 | 開催頻度未定 | 未確認事項として表示 |
| E07 | 希望時間帯が「未定」と具体時間を同時選択 | 入力の衝突として確認を促す |
| E08 | 必要設備未選択 | 「設備なし」と断定せず未確認 |
| E09 | 運営主体が未定 | 担当・責任者を確認する行動を優先 |
| E10 | 地区が未選択 | 実際の施設の自動提案をせず汎用確認 |
| E11 | 地区が選択されるが公共施設CSV未取得 | 未収録と明記、場所タイプ比較は継続 |
| E12 | 公共施設CSVに該当0件 | カバレッジの範囲が確認できた場合だけ「収録済みデータでは0件」 |
| E13 | 公共施設データ範囲外 | 0件としない |
| E14 | 施設の存在は確認済み、予約状況未確認 | 存在を表示できるが利用可能とは断定しない |
| E15 | 空き家の物件データがない | 空き家タイプは表示、実在する個別物件を紹介しない |
| E16 | 学習支援・子どもが参加 | 見守り責任者・安全を注意事項の別枠に保持 |
| E17 | meal、食事提供 | 食品衛生・調理/配食・運営者を要確認。法令適合は判定しない |
| E18 | shop、飲食内容が明示/不明 | 営業形態・所管窓口での確認を残し、飲食営業できると断定しない |
| E19 | 既存施設で条件が合いそう | 空き家へ誘導せず既存施設の確認を促す |
| E20 | 地域ニーズ未調査 | 一般の行動例へ。需要ゼロとは表示しない |
| E21 | 架空調査デモ | 全画面と根拠欄に架空を明記 |
| E22 | Q4障壁が対象活動不明 | 活動別の分岐に使用しない |
| E23 | Q8自由記述に未レビューの事実 | 用途固有の確定根拠にしない |
| E24 | 複数の行動が同じ意味 | 重複除去しruleId固定順で出す |
| E25 | 3件表示後に追加の確認がある | 「ほかの確認事項」と安全・専門家確認に到達できる |
| E26 | 実際の場所へのリンクが古い／URL未検証 | リンク公開を保留、一般的な確認方法を案内 |
| E27 | 同じ入力とデータ版 | 同じ文言・順番・理由を返す |
| E28 | 条件の変更で場所の案内が変化 | 改訂した条件だけで再評価。スコアは生まれない |

**実装後の受入試験は未実施**。活動者への聞き取りや実データ検証に応じてルールを見直す。
