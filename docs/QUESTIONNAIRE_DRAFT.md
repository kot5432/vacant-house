# 住民向けアンケート v0.3（配布前レビュー用）
最終更新：2026-11-12／**未配布・回答未収集**。本書は質問票の素案。調査責任者、学校・主催者の確認、取扱方法、予備調査を終えるまで公開フォームにしない。

## 調査の目的・冒頭の案内（仮）
「高岡市周辺の空き家の活用を考えるため、地域での困りごとや既存施設の利用について伺います。回答は任意です。回答しない設問や途中で終了することができます。氏名、電話番号、詳細な住所や実在する空き家の位置などは入力しないでください。回答は集計してコンテスト作品の検討・発表に利用する予定です。個人が識別される内容は公表しません。」

**配布前に必ず埋める欄**：調査責任者と所属［未定］／問い合わせ先［未定］／回答保存先［未定］／アクセスできる人［未定］／保存期間と削除方法［未定］／調査実施期間［未定］／利用目的と集計公開範囲［未定］。匿名回答で受付後の個別削除が難しい場合、その限界も事前説明する。必要な学校・主催者の承認、関係者の同意を確認する。児童本人への直接調査は初期対象にしない。

## 設問
**Q1. この地域との関わり（複数選択可）**：住んでいる／働いている／通学している／地域活動に参加している／その他／回答しない。
**Q1b. 対象の地区（1つ、分かる範囲で）**：博労／川原／戸出／高岡市内のその他／市外／分からない／回答しない。「住んでいる」の場合は居住地区、「働く・通う」の場合は活動する地区のどちらかを別途選択・表記する。**居住と活動を集計時に混同しない**。特定の町名や番地は聞かない。

**Q2. 地域で困っていること（複数選択可）**：交流の機会／子どもの放課後の過ごし方／食事や居場所／学習・仕事の場所／買い物／移動／困っていることは特にない／分からない／その他（任意自由記述）。選択肢は予備調査で確認する。

**Q3. 地域の公共施設・交流施設の利用状況（1つ）**：週1回以上／月に数回／年に数回／利用したことがない／施設を知らない／分からない／回答しない。

**Q4. 施設や活動を利用しにくい理由（複数選択可）**：場所が遠い／時間が合わない／費用／予約・手続き／内容が合わない／運営する人が足りないと感じる／特にない／分からない／その他。
**Q4b. その回答は、どの種類の施設や活動についてですか（任意）**：交流／学習支援／食事支援／仕事／店舗／その他／特定できない。**Q4bが未指定なら個別用途の分岐根拠にしない**。施設の実名は必須にしない。

**Q5. この地域にあるとよいと思う場所・活用方法（複数選択可）**：地域交流／学習支援／子ども食堂・地域食堂／コワーキング・創業支援／小規模店舗・カフェ／その他／特にない／分からない。**住宅・移住は別設問Q5b**：「住まいとして空き家を使うことについて、どのような関心がありますか（住むことを検討したい／地域への移住を応援したい／関心なし／分からない／回答しない）」とし、これを居住需要とみなさない。

**Q6. Q5で選んだ用途のうち一つ（任意）を選び、実際に利用したいと思いますか**：ぜひ利用したい／条件が合えば利用したい／利用しない／分からない／回答しない。Q6は**選んだ一用途の利用意向**と明記し、選ばれなかった用途を「利用しない」と扱わない。

**Q7. Q6の用途について、利用するならいつ・どのくらいですか（任意）**：頻度＝週1回以上／月に数回／年に数回／未定、時間帯＝平日昼／平日夕方／平日夜／休日／未定（それぞれ独立）。Q6未回答でも強制しない。

**Q8. そのほか、地域での困りごとや空き家の活用アイデア（自由記述・任意）**：名前や場所の分かる情報を書かない注意を表示する。回答は自動で用途・担い手不足と断定せず、集計前に担当者が内容を点検する。

## 集計の定義
- 回答者人数＝Q1関係の無回答を含む全有効回答件数。設問ごとの**有効母数は別**に記録。
- Q5の複数選択は用途別選択者数／当該設問に有効回答した人数。合計100%にはならない。
- Q6・Q7は「選ばれた一用途に回答した人」にのみ母数がある。Q5希望全員の利用意向へ一般化しない。
- 博労／川原／戸出が不明の回答は対象地区別の人数に按分しない。
- 自由記述のテーマ化は個人情報の除去・二者確認。原文を公開アプリやGitHubに置かない。
- 集計から推定される個人の再識別リスクが高い小集計は公開しない。
- 回答者全体の希望・利用意向と、地域人口全体の需要予測を混同しない。

## 予備調査で確認すること
1. Q1bの「居住地区」と「活動地区」を迷わず答えられるか。
2. Q4の障壁がどの用途に関係するか、Q4bで指定できるか。
3. Q5で「あるとよい」こととQ6で「自分が利用したい」ことの区別が伝わるか。
4. 住宅への関心と、施設の利用頻度を混同しないか。
5. Q6で一用途に絞ることが分かりやすいか。自由記述の個人情報注意が伝わるか。
6. 所要時間・読みやすさ・回答負荷。予備回答は本調査に混ぜず、修正時は質問票の版を更新。
