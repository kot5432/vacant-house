# 需要検証の再設計：地域で活動を始めたい人への聞き取り案
更新：2026-11-12。**配布・聞き取りは未実施**。責任者・同意・記録範囲の確認後に使う。

## 検証したい仮説
活動したい人にとって「希望する場所の条件と既存選択肢を比較し、準備の順番を決めること」が障壁になっている。空き家が必要なのは、その条件に既存施設が対応できない場合に限る。

## できれば先に聞く（誘導を避ける）
1. 実際にどんな活動を、誰と、いつ始めたいですか（具体例）。
2. 直近でその活動のために何をしましたか。実際に止まったのはどこですか。
3. 会場を探したことはありますか。何を使いましたか（施設のWebサイト、学校・公共施設、知人、AI等）。
4. 選んだ場所を使えなかった場合、何が障壁でしたか（時間／設備／人数／費用／許可／移動／運営人員）。
5. 会場以外の理由で始められていない点はありますか。
6. 空き家を使うこと自体に関心はありますか。関心がない場合は何が理由ですか。
7. 使っている既存サービスや相談先で、解決できた点・不足した点は何ですか。
8. 活動条件から候補となる場所タイプと確認事項を整理する仕組みがあれば、実際にどんな場面で使いますか（説明は行動事実を聞いた**後**にする）。

## 先に結論を決めない判断基準
- 活動者が場所・準備の具体的な障壁を過去の行動として説明できる。
- 既存の施設サイト・相談窓口・検索・AIだけでは解消できない情報や順序の問題が特定できる。
- 今回の案を見て、**新たに取れる最初の行動**を自分の言葉で説明できる。
- その活動に空き家が不要なら、空き家を強く推薦しない。
- 逆に資金・人材不足が中心なら「場所探し」だけをプロダクト価値と決めつけない。

## 記録と注意
本人の意向と実際に行ったことを区別。賛成した人数だけで需要を証明しない。面談相手の氏名、実物件所在地、子どもの個人情報などはGitHubやチャットに共有しない。学生団体の関心と参加意思、活動の継続可能性は別に確認する。
