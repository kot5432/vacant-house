## 暫定のプロダクト判断
1. 施設CSVを読み込むまでは**「周辺施設一覧が実データで動く」と言わない**。
2. 地図表示に出せるのは、取得・ライセンス・座標・カバレッジを検証した施設だけ。
3. CSVのジャンルとアプリの「教育／交通／仕事」など6分類を直接一対一でマッピングしない。分類に漏れと重複があるため、実物のサンプルをレビューして決める。
4. 地区の行政統計値と、概略ピンから1km以内に存在する施設数は別の空間単位。
5. 完全性不明なら「収録済みデータで確認された施設」と表示し、近隣施設がないとは結論しない。

## 2026-11-12 再取得と収録範囲の評価
**再取得の試行結果**：
- Web経由の公式CSVリンク：配信content-typeが `application/octet-stream` として扱われ、閲覧ツールで開けなかった。
- Web経由の公式Excelリンク：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` のため、同ツールではファイル中身を展開できなかった。
- ローカル実行環境のファイルダウンロード／HTTP接続：取得に失敗。PythonのHTTP要求では `www.city.takaoka.toyama.jp` の名前解決エラー。
- CSV実ファイルの読み込み、総行数、全ジャンルの件数、座標検査、重複検査は**未実施**。公式HTMLにあるファイルサイズ・掲載項目と混同しない。

### 13ジャンル→アプリで使用する施設カテゴリの暫定対応
| 市のジャンル | アプリ側で検討する分類 | 注意 |
| --- | --- | --- |
| 子育て | childcare | 保育園・児童センター等。すべてが一般利用可能とは限らない |
| 学校・教育 | education | 教育施設の存在≠学習支援ニーズ |
| コミュニティ施設 | community | 公民館・地域交流センター等。開館・利用条件を別確認 |
| 文化・生涯学習 | community / tourism_culture（個別確認） | 図書館や博物館などを用途別に審査する |
| 観光・産業 | tourism_culture / commerce_work（個別確認） | 観光施設や工業団地は「店舗」や「コワーキング」の実在を直接示さない |
| 交通 | parking_bicycle（**別分類候補**） | 市の例示は駐車場・駐輪場。駅・バス停を網羅しない |
| 健康・福祉 | daily_life（必要なら） | 施設の対象者・利用条件は異なる |
| スポーツ、公園・緑地 | recreational（MVP外または補足） | 学習・交流需要に直接変換しない |
| 市庁舎、公営住宅、環境・衛生、防災 | MVP利用対象外または個別表示 | 地域への存在と用途適合を短絡しない |

**設計上の結論**：アプリの6分類に行政の13ジャンルを機械的な一対一変換してはいけない。交通機関・商業店舗などは市の公共施設CSVとは別ソースで調査する。施設が収録されていないカテゴリは**none**ではなく**not_collected**として表示。

### 公式HTMLで確認できた既存拠点
高岡市の[地域交流センター一覧](https://www.city.takaoka.toyama.jp/soshiki/kyosomachizukurika/3/5/2/10189.html)には、**博労地域交流センター・川原地域交流センター**が掲載されている。CSVの収録確認前でも、少なくとも地区に公的な交流拠点が存在することを知るための参照資料になる。ただし**アプリの施設データとしての実装・座標の検証はまだ行っていない**。
