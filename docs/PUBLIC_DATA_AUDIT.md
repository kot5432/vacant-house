- 座標は世界測地系とされる。**小数表記、列分割、CRSのEPSGコードの確認はCSVの取得後**。
- 13ジャンル：市庁舎、子育て、観光・産業、文化・生涯学習、スポーツ、健康・福祉、学校・教育、公園・緑地、公営住宅、コミュニティ施設、交通、環境・衛生、防災。

- 新旧の番号が併記され、廃止施設の番号は欠番、追加施設は一覧末尾。IDと並び順を同一視しない。
- データライセンスは原則CC-BY（表示）、個別指定がある場合はそちらが優先。出典・加工したことの明示が必要。
- 市は完全性・正確性の保証をしない。データが改変・移転・削除され得る。

## 暫定のプロダクト判断
1. 施設CSVを読み込むまでは**「周辺施設一覧が実データで動く」と言わない**。
2. 地図表示に出せるのは、取得・ライセンス・座標・カバレッジを検証した施設だけ。
3. CSVのジャンルとアプリの「教育／交通／仕事」など6分類を直接一対一でマッピングしない。分類に漏れと重複があるため、実物のサンプルをレビューして決める。
4. 地区の行政統計値と、概略ピンから1km以内に存在する施設数は別の空間単位。
5. 完全性不明なら「収録済みデータで確認された施設」と表示し、近隣施設がないとは結論しない。
