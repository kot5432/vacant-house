# コンテスト作品部門・応募準備 v2.0（現行は設計のみ）
更新：2026-11-12。**開発・公開・提出は未実施**。公式要項は応募直前に再確認。

## 一文で
**地域で始めたい活動が決まっている人が、公共施設・空き家・その他の会場を検討し、活動に向けた準備と最初の行動を整理するWebアプリ。**

## 今回の特徴（現時点では価値仮説）
1. 施設を選ぶ前に、活動の**参加人数・時間帯・必要設備・運営体制**を整理。
2. **既存施設を第一に無視せず**、空き家が必要な理由も問い直す。
3. 実際の利用許可・空き家物件・地域の需要を断定せず、次の具体的な確認方法を示す。
※既存サービスにない価値かどうか、活動希望者への聞き取りと比較で検証が必要。

## MVPの受入条件（実装後に検証）
- [ ] 活動カテゴリ（5種類＋other）を選び、不明条件があっても入力できる。
- [ ] 既存公共・地域施設／空き家／その他会場の3タイプを確認できる。
- [ ] 各タイプに、何を確かめるかと最初の具体的行動・理由が表示される。
- [ ] 学習支援の子どもの安全、食事提供の衛生、店舗の法令等の注意を省略しない。
- [ ] 空き家の物件検索・予約や利用許可があるような表現をしない。
- [ ] 架空・実データ・未調査・未収録の状態が区別される。
- [ ] 未収録データがあっても一般的な行動ガイドは使える。
- [ ] 入力保持、狭幅表示、キーボード、入力エラーの受入条件を満たす。
- [ ] 初見利用者が「次にできる行動」を一つ説明できるかを確認する（未実施）。

## 紹介動画構成案（9分程度の仮案）
1. 課題：やりたい地域活動は決まっていても、場所・準備の条件を整理しにくい（**仮説**）。
2. 活動を入力：学習支援を始めたい学生団体の**架空例**。
3. 場所の選択肢：既存の交流施設と空き家、民間会場の違い。
4. 次の一歩：人数・時間・責任者・施設利用条件・建物の安全などを具体的に確認する。
5. 技術：ルールの説明可能性、情報の出典・未確認を区別。
6. 実際に行った検証だけを説明し、未調査・架空は明示。
7. 今後の可能性：実際の施設情報の拡充、空き家・活動者の連携（**未採用の将来案**）。
8. **生成AIの活用方法**：ChatGPTでの企画・設計・調査準備・文書化を明記し、コード利用があれば追加。
