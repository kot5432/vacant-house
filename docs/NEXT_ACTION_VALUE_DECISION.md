# 中心価値の決定記録 v2.0：活動を始めるための次の一歩
更新：2026-11-12／**設計のみ**。

**最新の決定**：主対象は「始めたい活動の内容が決まっている人・団体」。持ち帰る価値は**「どんな場所で活動できそうかを検討し、次に確かめること・最初の具体的な行動を把握できること」**。

## 体験
1. 始めたい活動・参加人数・時間・設備・運営状況を入力。
2. 既存の公共・地域施設、空き家、その他の会場を、確認ポイントで比較する。
3. 最初の行動カードに**確認事項、具体的な行動、確認方法、理由/根拠、注意点**を表示。
4. 行動の実施や施設利用を保証するのではなく、本人が何を確認するか決める。

## 重要な変更
旧v1の「所有者の希望・設備3条件から6用途を整理」は現MVPでは実施しない。6活動カテゴリ（community、study、meal、work、shop、other）は**活動内容の入力**であり、空き家の用途適合診断ではない。住宅・移住は対象外。

## 具体的な一歩の例
- 学習支援：参加する子どもの人数・時間帯、責任者を整理し、既存施設の利用条件を確認。
- 子ども食堂：運営主体、食事の提供方法、衛生・安全の相談事項を整理。
- 地域イベント：希望人数・時間に合う公共/地域施設を先に調べ、合わない理由を確認。
- 空き家：所有者の使用許可、契約・設備・整備費・安全/法令を調べる必要性を説明。**実在物件の提供は行わない**。

## 不変条件
場所タイプの客観ランキングなし。実調査と架空の区別。協力意思・予約可能・許認可・収益・安全を保証しない。地域の実データなしでも一般案内は可能。学生団体のマッチングは将来検討。
