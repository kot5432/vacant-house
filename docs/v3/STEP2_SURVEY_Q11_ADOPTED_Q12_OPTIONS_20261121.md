# STEP2｜アンケートQ11 A案採用・Q12検討（2026-11-21）

## 正式決定：Q11 主催準備で実際に取った行動

- **質問**：「イベントを企画・準備した際、必要な情報をどのように調べたり、困りごとを解決したりしましたか？」
- **形式**：チェックボックス（複数選択）
- **選択肢**：
  1. 自治体の公式情報を調べた
  2. 会場・施設に問い合わせた
  3. 経験者・知人に相談した
  4. SNS・検索エンジンで調べた
  5. チェックリスト・手引きを利用した
  6. 準備・開催を延期または見送った
  7. まだ準備した経験がない
  8. 覚えていない・回答しない
  9. その他
- **目的**：現在の代替手段や、準備の中断・延期といった実際の行動を把握する。延期・見送りを選んだことだけで、特定の情報不足が原因だったとは断定しない。
- **分岐・排他**：「まだ準備した経験がない」「覚えていない・回答しない」は他の選択肢と排他的に扱う。Q4で主催の準備経験がない人にはQ11を強制せず、最終フォームでは分岐または非該当選択肢を利用する。Googleフォームでの実際の制御方式は最終設計時に確認する。
- **分析**：Q4の開催経験・準備段階と組み合わせ、経験者の実行行動と未経験者の予想を混同しない。

## 次の検討：Q12（未決定）

**目的**：現在ある情報や支援だけで主催準備が進められたかを確認し、中心価値「準備の全体像・優先順位」に対する不足を、アプリが欲しいかどうかという誘導なしに確かめる。

- **A案（推奨）**：「イベントの企画・準備に必要な情報は、既存のサイトや周囲の人への相談などで十分に得られましたか？」（単一選択：十分に得られた／おおむね得られた／一部足りなかった／ほとんど得られなかった／まだ実際に調べたり準備した経験がない／覚えていない・回答しない）。後続で不足内容を聞く場合は任意にする。
- **B案**：「既存の情報で特に不足していたことは何ですか？」（複数選択）。具体的不足は分かるが、十分だった人の経験を取りこぼしやすい。
- **C案**：「もっとも役に立った支援・資料があれば教えてください」（任意自由記述）。有効な代替手段が分かるが、情報の充足度を直接測れない。

**Q12はユーザー選択待ち**。まだ正式採用しない。
