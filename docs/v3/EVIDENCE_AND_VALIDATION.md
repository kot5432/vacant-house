# 需要・独自性の現行評価 v3.1
更新：2026-11-12。**机上調査完了／個人・チームへの直接聞き取り未実施／試作品比較未実施**。

## 結論
**社会課題の存在：確認できる。活動開始時の障壁：他自治体の登録団体調査で確認できる。高岡市でのアプリ利用需要：未確認。競合より良いか：未検証。**
いまは「開発決定」ではなく、「具体的な独自価値仮説を紙で検証する」段階。

## 何が分かったか
- 高岡市こども計画：中高生が自由に過ごせる施設を望む割合49.8%（2024年資料）。これは活動主催者/アプリ利用者の割合ではない。
- 愛知県東海市2024年登録団体調査：236団体に配布・81回答、立ち上げ時の参加者確保44.4%、場所確保37.0%、資金確保35.8%。複数回答、**富山の個人へ一般化しない**。
- 高岡市サポナビ：個人の「活動を始めたい」「団体を探したい」相談事例も案内。市民活動相談窓口、地域交流センター予約システムがすでにある。**相談・施設検索の代替品なら必要性が弱い**。
- 高岡市地域交流センターの「利用上の注意」（R8.1改定）に「未成年者のみで利用するとき」は利用できない旨。これは**具体的な確認条件を取り違えない案内**が必要な好例。
- 高岡市2026年度市民共創チャレンジ事業は、連携団体や事業内容に条件がある。単発企画を行う個人が当然に対象とは言えない。

一次資料と競合対応の詳細：[DEMAND_AND_COMPETITOR_AUDIT.md](DEMAND_AND_COMPETITOR_AUDIT.md)。

## 検証する唯一の強い差分
**「今の障壁×個人/チームの状況×高岡市の実際の条件」から、活動前に『誰に何を確認するか』を具体化できるか。**
個人・立ち上げ前チームが既存サービスを使うための**準備を支援する**設計。コンシェルジュ、マッチング、申込み代理、参加者集客、施設の利用判定はしない。

設計案：[VALUE_PROPOSITION_V31.md](VALUE_PROPOSITION_V31.md)／[画面](USER_FLOW.md)／[ルール](DECISION_RULES.md)。

## 今後必要な実証
- 実際に活動を始めようとしている個人とチームに、**実際に止まった経験と既存手段の不足**を聞く。
- 公式ページ・一般検索/AI・紙/文章によるv3.1画面案を同一課題で比較し、**見落とす地域の制約・具体的な最初の行動・相談内容**を評価。
- アプリを見せる前に障壁を聞く。「使いたい？」だけの誘導質問は需要の根拠にしない。
- 成果は人数・条件・失敗例を含めて公表し、地域全体の利用率を推定しない。

具体的な調査票と進退基準：[VALIDATION_PROTOCOL_V31.md](VALIDATION_PROTOCOL_V31.md)。

## 判断
- **続行する**：複数の活動者に現実の障壁があり、既存サイトより正しく/具体的に次の行動を理解する事例がある。
- **機能を再設計する**：場所・手順が主要因ではなく参加者や費用が主因、または一般助言にしかならない。
- **方向転換/停止する**：既存サイト・相談で十分、情報更新の運用が不可能、活動可能と誤認させる危険が解消できない。

**この評価は入賞可能性・売れる見込みの確定ではありません。** コンテストの地域課題のテーマに合うかと、実際に必要とされるかは別。
