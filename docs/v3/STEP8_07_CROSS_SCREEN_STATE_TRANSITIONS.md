# STEP8-⑦｜U01〜U04 状態遷移と保存境界の横断シナリオ（設計・未実行）

作成：2026-11-16。**新機能採用ではなく、ADR-001〜027の既決仕様に対する期待結果を整理したもの**。地域イベント準備支援Webアプリ専用。旧空き家案の機能・データなし。実装・テスト実行・デプロイ・利用者検証なし。

## 共通不変条件

- 本人の入力・進捗はイベントIDで分離し、タスクの判定結果と保存済み本人進捗を別レイヤにする。
- U02は初回生成を成功するまで永続保存しない。U03進捗は本人操作後に保存成功を表示。U04は保存確定まで元レコードを変更しない。
- U04とU03の保存は**最新revisionの楽観的競合検知**を通る。古いタブからDBの新しいレコードを丸ごと上書きしない。失敗を成功扱いしない。
- **戻る・更新・強制版変更**によって未保存入力の消失を無条件に起こさない。U02/U04のページ再読込を保証しない既決条件は守り、更新が必要ならユーザーの明示意思を優先する。
- 公式出典の失効／更新はP01〜P12の表示だけを再評価し、本人の進捗・needsRecheckを勝手に消去しない。
- バックアップJSONに含めるのは保存済みEventRecordだけ。出典や導出結果、U02/U04ドラフト、U03の未コミット差分は含めない。

## 画面と保存境界（確認表）

| 移動・操作 | 永続化するもの | 失敗・キャンセル時 | 根拠 |
|---|---|---|---|
| U01→U02新規作成 | なし | 入力開始前、DB不変 | U02下書き非永続 |
| U02段階1→2→3 | 同一画面内の回答保持のみ | 初回保存前はDB不変 | U02仕様 |
| U02→U03初回生成 | 検証済み入力・初期進捗レコード | 保存失敗ならU02回答維持、U03へ遷移しない | 初回保存 |
| U01→既存U03 | 保存済み読取のみ | 読込失敗は未読込を案内 | U01/U03 |
| U03→進捗変更 | 該当タスクの進捗とrevision | 保存失敗は成功表示なし、古い入力で上書きなし | ADR-026 |
| U03→明示再確認解除 | 当該needsRecheckとrevision | 失敗・競合時は解除したと表示しない | ADR-004 |
| U03→U04編集 | ドラフトだけが変化 | キャンセルなら既存レコード不変 | U04仕様 |
| U04→保存確定 | 新しい入力と必要な再確認、revision | 競合なら手動確認、無断統合なし | ADR-005/026 |
| U01→JSON書出し | DB変更なし、保存済み選択レコードだけ | 失敗・2 MiB超は書出し成功としない | ADR-019〜021 |
| U01→JSON取込み | 本人承認後に新イベント全件を追加 | 取消/検証エラー/競合で既存DB不変 | ADR-016〜018,022,023 |

- **FLOW-20**のような未採用P1/P2/P3の適用条件は、文言設計だけで補えない。実際の初期プランの並びを変えるため、別の製品判断が必要。
