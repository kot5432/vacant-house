# STEP2｜Googleフォームの対象B案採用（2026-11-21）

- 決定：アンケート対象は**高校生・高専生＋大学生・社会人**を採用する。
- 富山県内の地域イベントに参加・企画することに関心がある人を中心に募り、活動に関心が薄い回答者も除外せず記録する。
- 調査方法：Googleフォーム（前段の決定）。3〜5分程度を目安。氏名・メールアドレス等を原則収集しない。
- 参加希望者／初主催者・主催経験者の回答を分けて分析する。標本が小さい段階で富山県全体を代表する結果とは扱わない。
- 質問設計：実際の行動・困った経験・既存の代替手段を優先。「困らなかった」「参加・検索経験なし」等の中立的選択肢を用意する。
- 現段階では**対象のみ確定**。質問文・分岐・配布先・同意と保管ルール・実施日は順次検討。フォーム作成・配布・回答収集は未実施。
