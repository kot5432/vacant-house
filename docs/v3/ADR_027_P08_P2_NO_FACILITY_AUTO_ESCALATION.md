# ADR-027｜施設固有条件でP08をP1に自動昇格せず、P2で公式確認を案内（A案正式採用）

決定日：2026-11-16。利用者が[STEP8-③比較](STEP8_03_FACILITY_P08_PRIORITY_GATE.md)の**A案を明示採用**。現行の「初めて単発・小規模の地域イベントを主催する人向け準備支援Webアプリ」のみ。旧空き家・物件登録・所有者診断・マッチングとは無関係。**設計のみ、コード実装・動作試験・デプロイなし**。

## 1. 正式決定

- **初期MVPでは、地域・会場・施設カテゴリ・行政の公式出典が一致していても、施設固有条件だけを理由にP08「利用条件・手続き」をP1へ自動昇格させない。**
- P08は**P2を基本の準備優先度**として扱い、「利用する会場・場所の条件を公式窓口で確認しましょう」という**確認行動**、対象と有効性を検証できた公式ページのリンク・確認日を示す。P2は法的義務・申請必須の断定ではない。
- **公式出典の対象が確認できない場合、施設カテゴリを本人が選んでいない場合、または出典が期限切れ／未点検の場合は、施設固有の断定的な説明を表示しない**。公式窓口での確認という一般的なP08行動は維持する（ADR-009〜012）。
- 物理会場なしのP08親は既定どおり**`applicable=needs_information`・P2**で、建物予約等の専用子項目のみ非該当（ADR-002/003）。「オンライン開催」「許可不要」と補完しない。
- **P05（見守り・安全）**の正式優先度は維持：未成年のみ／両方=P1、成人のみ／対象未定=P2。同優先度ではタスクIDの数値が小さい順（ADR-003）。P05のP1をP08に置き換えない。
- 保存済みの本人進捗・対象外判断・`needsRecheck`は順位の表示変更だけで書き換えない。再確認は本人の明示操作＋保存成功のみ解除（ADR-004/026）。
- 将来、施設固有条件によるP08のP1自動昇格を導入する場合は**別の高影響な製品判断**として、実際の公式資料の適用範囲・鮮度・条件と利用者理解の検証を経て再承認を要する。初期MVPへ無断追加しない。

## 2. 判定と表示の設計上の境界

| 条件 | P08親の表示 | 優先度 | 公式施設情報 |
|---|---|---|---|
| 会場未定 | 利用条件・手続きの確認 | P2基本 | 施設固有内容は未適用 |
| 会場候補／確定・本人が明示した施設カテゴリと有効出典の対象一致 | 会場・場所の利用条件を確認 | **P2維持** | 出典リンク、確認日時、対象範囲に限定した確認事項を提示 |
| 上と同じだが出典が期限切れ／未点検 | 一般的な利用条件の確認 | **P2維持** | 施設固有の断定を停止、確認先の一般案内へ戻す |
| 高岡市だけ一致／施設の自由記述だけが似ている | 一般的な利用条件の確認 | **P2維持** | 特定施設の規則を自動適用しない |
| 物理会場なし | 開催形態・場所の利用条件の要否を確認 | **P2確定** | 建物固有子項目は非該当、親は要情報 |

**P08をP2基本とすることは本決定**。既存P01〜P12の他タスクのP1/P2/P3候補、適用判定を一律変更するものではない。施設固有の出典を理由にP08優先度を変える以前の草案記述は、このADR-027が優先する。

## 3. U03画面文言の候補

- 見出し：「会場や開催場所の利用条件を確認しましょう」
- 理由：「利用する場所によって、確認することが異なります。候補が決まったら公式情報や窓口をご確認ください」
- 条件付き出典が有効な場合：「対象となる施設の公式情報を見る」＋ページ名・確認日。本人の施設の同一性が未確定なら施設固有の条件を断言しない。
- 出典が古い場合：「この施設に関する情報は確認が必要です。最新の内容を公式窓口でご確認ください」など。以前確認した内容を「現在も有効」と表示しない。
- 完了履歴や要再確認は独立した状態として見せる。「P2＝必要な行政申請」と誤解させない。
