# STEP2｜アンケートQ4 A案採用・Q5検討（2026-11-21）

## 正式決定：Q4 企画・開催経験を段階別に聞く

- **質問**：「地域イベントや体験会などを、自分で企画・開催した経験はありますか？」
- **形式**：単一選択（本人が最も近い状態を選ぶ）
- **選択肢**
  1. 主な企画・運営担当として開催したことがある
  2. 企画・準備したことはあるが、開催には至らなかった
  3. 開催したいと考えたことはあるが、準備はしていない
  4. 企画・開催を考えたことはない
  5. 回答しない
- **目的**：開催経験者、準備段階で止まった人、関心段階の人、主催に関心がない人を区別し、主催側の後続質問を調整する。
- **運用上の注意**：複数経験がある場合は最も進んだ段階を選ぶ旨を補足する。単に手伝った経験と主担当の企画・開催を混同しない。回答しない人にも調査を続ける道を用意する。Q4単独で「参加が主催につながった」と断定しない。

## Q5の選択肢（未決定）

**目的**：アプリの中心コンセプト「参加から自分でも企画したくなる」という経験が実際にあるかを、誘導せず確かめる。

- **A案（推奨）**：「地域イベントや活動に参加した経験をきっかけに、自分でも何かを企画・開催してみたいと思ったことはありますか？」（単一選択：ある／ない／参加した経験がない／覚えていない・回答しない）。参加経験のある人のみを想定した分岐にしてもよいが、Q3-2と矛盾しない設計が必要。具体的な動機の自由記述を必須にしない。
- **B案**：参加経験との関連は問わず「今後、自分でイベントを企画したいですか？」（ある／ない／分からない）。現在の意向は分かるが、参加から主催のつながりは分からない。
- **C案**：主催に興味を持ったきっかけを複数選択で問う（参加したイベント／学校・知人／SNS／地域の課題／その他／主催に関心なし）。きっかけの幅は取れるが、選択肢の設計が複雑になる。

**Q5は未確定。** 設問の正式文言・分岐・全体の長さは今後最終調整する。
