# STEP 3｜MVPの機能範囲（2026-11-13）
**順序：STEP1課題→STEP2価値→本書。これは今後の実装を許可する指示ではない。**
本MVPの仕事は「人材確保・会場予約」ではなく、**活動開始前の確認事項を本人が把握し、次の具体的な行動を決めること**。

## Must（作るときに必要な最小機能）
| ID | 機能 | 利用者に渡す結果 | 受入基準（実装後の試験項目） |
| --- | --- | --- | --- |
| M1 | 活動・本人の状況の入力 | 活動の種類、個人/チーム、今の困りごと、準備状況 | 必須2項目以外は不明で進める。個人・小規模チームに対応 |
| M2 | 決まった/未定の整理 | 規模・日時・設備・責任・協力の確認項目 | 不明を「条件が満たされた」や「不可」と扱わない |
| M3 | **最初の確認カード** | 誰に、何を、なぜ、どう確認するか | 状況を変えれば質問と確認先が適切に変化。最優先1件＋補助最大2件 |
| M4 | **高岡市の公式情報と注意** | 根拠URL・確認日・対象施設・未確認の範囲 | 当該施設を検討する場合のみ利用制限を表示。利用可否を断定しない |
| M5 | **相談文の下書き・コピー** | 活動の説明、未定の条件、確認したい質問 | 本人が確認・編集後にコピー。送信・保存しない |
| M6 | 例外・安全・基本操作 | 子どもの安全上の確認と、無理な案内をしないこと | 入力不足、地域外、子ども関連、未成年のみ、公式情報未確認、スマホ・キーボード対応 |

## Should（期間に余裕があれば）
- 既存公共施設、既存団体拠点、空き家を「確認事項の種類」で比較する簡単な補助画面。
- 相談文を印刷/手動ダウンロードする機能。ログイン・永続保存は要らない。
- 当人が「今回はこの確認を先にしたい」と選び直す機能。

## 今回作らない（旧案との混在禁止）
- 旧・空き家所有者の希望A/設備Bによる6用途診断、住宅・移住診断、物件スコア、独自の空き家バンク。
- 実際の空き家・仲間・活動団体のマッチング、賃貸契約や施設予約の代行。
- 活動資金の提供、補助金の適格判定、営業・食品衛生・安全の自動認定。
- 汎用AIチャット、自由記述からの自動活動判定、実在する利用需要の自動予測。
- 会員登録・コミュニティSNS・DM・長期の活動管理。

## 機能を減らすときの優先順位
装飾→地図→場所タイプ詳細比較→印刷・共有→細かい地区情報の順に削る。
**M1/M3/M4/M5、子どもの安全上の注意、検証可能なルールは残す。**

## これをもって「MVP完成」と言うための条件
- 2人以上の異なる利用状況で、**異なる具体的な事前確認**が表示される。
- 確認事項の理由・出典または「一般的助言」が明示される。
- 利用者が「最初の行動」と「相談したい相手に聞く質問」を理解できるかを別途検証（未実施）。
- 予約/許可/協力を得たかのような表示がない。
- 現時点は仕様のみ。上記は**開発・動作テスト実施後の受入基準**。

## 同時に残す未解決項目
- 現在の公的情報の件数で、個人・チームの多様な活動に十分な差が出るか。
- 活動者が本当にこの問題で止まっているか。
- 相談文コピーが現場で役立つか。
これらが分かるまでは、MVPを無闇に拡大しない。
