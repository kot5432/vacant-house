# STEP2｜アンケートQ3 A案採用とQ4検討（2026-11-21）

## 正式決定：Q3は参加経験と検索経験の両方を把握

- 利用者決定：A案を採用。
- **Q3-1（検索）**「過去半年ほどの間に、地域イベント・体験会・交流会・ボランティア活動などを自分で探したことはありますか？」
  - 単一選択：ある／ない／覚えていない・回答しない
- **Q3-2（参加）**「過去半年ほどの間に、そのような地域イベント・活動に参加したことはありますか？」
  - 単一選択：ある／ない／覚えていない・回答しない
- Googleフォーム上ではQ3のテーマを**2つの短い設問**に分割する。参加したが自分で探していない人、探したが参加していない人、両方した人、どちらもない人を区別し、矛盾した単一選択を避ける。
- 「地域イベント」は地域の講座・体験会・交流会・発表会・ボランティア等を含む。学校行事や授業を含めるかは事前に同じ説明を提示して統一する。特定イベント名・参加者名は聞かない。
- Q3-1/2の回答で参加経験の有無を決めつけず、後続の質問では未経験者向けの「経験なし・該当なし」を用意する。実際の行動データを機能への賛成と混同しない。

## 次の検討：Q4（未決定）

**目的**：初めて企画する人の困りごとを、経験者/未経験者を区別して把握するため、企画・開催の経験段階を聞く。後続の主催側質問の分岐に用いる。

- A（推奨）：「地域イベントや体験会などを、自分で企画・開催した経験はありますか？」（単一選択：主な企画・運営担当として開催したことがある／企画・準備をしたが開催には至らなかった／開催したいと考えたことはあるが準備はしていない／企画・開催を考えたことはない／回答しない）。共同主催や手伝いだけの場合の扱いは説明で補足。
- B：「企画・開催経験はありますか？」（ある／ない／回答しない）の簡易版。検討段階と主催経験者を区別できない。
- C：主催経験を聞かず、次の設問で「参加をきっかけに開催したいと思ったことがあるか」を聞く。中心コンセプトの検証には近いが、主催側の分岐には情報不足。

Q4は利用者の選択を待つ。参加をきっかけに主催したいと思った経験は、主催経験と混同せず、後の独立質問で確認する。
