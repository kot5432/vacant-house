# STEP8-③｜施設固有の公式条件がある場合にP08をP1へ自動昇格させるか（大きな判断・未決）

作成：2026-11-15。**利用者の確認が必要な製品判断**。現行アプリは「地域イベント主催者に準備の優先順位と最初の一歩を示す」ことを中心価値にする。P01〜P12判定監査：[STEP8-②](STEP8_02_RULES_CORE_VALUE_AUDIT.md)。**まだどの案も正式採用していない**。旧空き家関連のデータ・機能は対象外。実装・試験・現行公式原ページ検証なし。

## 背景と影響

P08「会場の利用条件・手続き」を早めに確認する必要があると伝えたいが、公式情報に書かれた**案内事項と、法律・施設利用の義務をアプリが確定したこと**は異なる。P1へ上げると、他のP1（P05未成年向け安全など）と同じ強調になり、初めての主催者が「申請必須」と誤認する可能性がある。

## 3案

| 案 | P08施設固有条件が成立した場合 | 強み | 留意点 |
|---|---|---|---|
| **A（慎重な推奨）** | **P08はP2を基本に保ち、検証済みの公式出典へのリンク・確認事項を表示。施設別のP1自動昇格は初期MVPでは行わない** | 出典確認や利用者検証が未完でも過度な断定を避けられる。P05の正式P1は維持 | 会場手続きの重要性を順位として強調しにくい |
| B | **出典が最新・対象地域／施設種別／主催者条件に一致し、明示した重要確認条件のルールが検証済みの場合だけP1に昇格** | 条件が本当に対象なら優先確認を目立たせられる | 施設出典運用、重要条件の分類、試験が重くなる。アプリの提示根拠に責任 |
| C | **会場が候補または確定したら、公式出典がなくても自動的にP1** | 簡単で目立つ | 会場が決まっただけで手続きの重要性を過大評価しやすく非推奨 |

**Aを現時点の安全側の推奨**。資料確認と初期利用者の理解度テストが終わるまでP08の施設固有P1を初期MVPに含めず、一般的な「会場の利用条件を公式窓口で確認」をP2で案内する。**利用者がAを採用するまでは、施設固有P1自動昇格の無効化を正式採用と扱わない。**

## 既決と共通の不変条件

- [ADR-003](ADR_003_PRIORITY_RULES_ADOPTED.md)：P05未成年／両方=P1、成人／対象未定=P2、同順位はタスクID昇順。**P08のno_physical_venue親はP2**（applicable=needs_information）を変えない。
- [ADR-002](ADR_002_NO_PHYSICAL_VENUE_SCOPE.md)：物理会場なしで建物専用の子項目のみ非該当、オンラインと断定しない。
- [ADR-009](ADR_009_OFFICIAL_SOURCE_MONTHLY_RELEASE_REVIEWS.md)〜[ADR-012](ADR_012_BUNDLED_OFFICIAL_SOURCE_CATALOG.md)：出典点検期限超過で施設固有の断定案内を停止、保存進捗は維持。
- 会場が「候補・確定」でも、**予約可・許可済み・申請不要・法定義務**を断定しない。
- 表示順序P1→P2→P3と代表1件＋他P1の表示、本人の進捗保持／再確認の独立を維持。

## 大きな変更として確認をお願いする理由

P08をP1に昇格させる基準は、アプリが「最初に着手すること」を大きく変える。未検証の公式情報や不明な開催条件をもとに強い優先順位を出すリスクがある。そのため、**この一件のみユーザー承認を待ち、細かな文言やテスト表の充実は委任範囲で進める**。
