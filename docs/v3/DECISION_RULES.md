# 判断ルール v3.0 — 活動準備と「最初の一歩」
作成：2026-11-12。**現行v3の論理仕様／未実装・未テスト**。旧所有者A/B診断やv2場所タイプ別の「適合診断」は使わない。

## 1. 処理するもの／しないもの
**処理する**：明示的に選択された活動カテゴリ・個人/チーム・協力者・責任者・人数・日時・地区・場所条件から、決定的な定型ルールで準備状況と最初の行動を示す。
**しない**：個人・子ども・物件の情報取得、自由記述からのAI推論、会場空き状況検索、活動の安全/法令適合/成功確率判定、補助金採択や団体協力の保証、地域の課題の実測推定。

## 2. 入力の型と扱い
- activityType = child_place / community_event / other（必須、1つ）
- startingMode = solo / forming_team（必須、1つ）
- supportPeople = available / looking / unknown（未選択はunknown）
- responsibleLead = available / coordinating / unknown（未選択はunknown）
- district = confirmed_takaoka_area / another_area / unknown（地区別データは実際の出典が確認された場合だけ結合）
- participantCount = 1以上の整数 / unknown。0・負数・小数・NaN・∞を自動変換しない。エラーは欄の近くに表示。
- schedule = known / unknown、frequency = one_off / recurring / unknown
- equipmentNeeds = 配列、選択なしは「不要」ではなく「未確認」
- optionalDescription = 文字列（任意）。**ルールの根拠に使わない。** 個人名・詳細住所・子どもの情報を入力しない注意を表示。

## 3. 最初の行動の優先ルール
同じ条件、同じruleVersionおよび確認済み出典版なら、同じ結果（表示順・文面・理由）を生成する。以下の優先順で同義の候補を重複排除し、**最初の一歩を1件、補助行動を最大2件**示す。

| ruleId | 適用条件 | 最優先の行動候補 | 理由／注意 |
| --- | --- | --- | --- |
| R10 | child_place かつ責任者available以外 | 成人の協力者・既存団体などと責任体制を相談する | 子どもの見守り等は場所より先に検討。単独開催を促さない |
| R20 | solo かつ協力者looking/unknown | 活動内容を短く整理して、市民活動相談窓口や既存団体への相談先を確認する | 活動を一人で抱え込まない |
| R30 | forming_team かつ責任者available以外 | チーム内で活動責任者と役割の相談をする | 運営を継続する体制が未定 |
| R40 | 人数unknown または日時unknown | 参加人数・開催時間の仮の目安を決める | 施設利用条件を比較するための情報が不足 |
| R50 | それ以外 | 既存の公共/地域施設の利用対象・設備・希望時間帯を公式案内で確認する | 会場候補の条件確認は空き家転用より軽い場合がある |
| R60 | 特定の利用障壁が**根拠付き**で示されたとき | 対象施設の実際の利用時間・制約を確認する | アンケートの回答だけで施設不足を断定しない |

**注**：R60はR50等に代わる追加候補として扱う。R10〜R50と重なるなら重複を除去。実データの採用条件を満たすまで発火しない。未確認の施設利用障壁を勝手に作らない。

## 4. 最初の一歩と相談文の紐づけ
各結果には次を必ず付ける：
- ruleId、ruleVersion、priority
- questionText：何を確認したいか
- firstActionText：今できる具体的行動（動詞ではじめる）
- actionMethod：調べる／自分で整理／チームと相談／窓口・活動団体に相談
- reasonText：なぜこの一歩か（入力に基づく説明）
- sourceRefs[]：根拠がある場合の公式情報URLや版情報。ないときは「一般的な準備事項」
- caveats[]：現地未確認、安全/法令の非保証

相談文は活動種類・個人/チーム・人数・時間・必要設備・相談目的を定型文へ埋める。**未入力なら「未定」**、決めたと捏造しない。コピーのみ、アプリ側から送信しない。個人情報・自由記述を送信先へ自動送信しない。

## 5. 会場候補を扱う方針
- existing_public：地域交流センター等の**既存の公共・地域施設**。利用対象・承認・設備・予約方法・利用料を要確認。
- shared_base：既存の活動団体が運営する拠点／民間会場。相手の承諾・継続使用・費用・安全を要確認。
- vacant_house：空き家。所有者の意思、契約、工事や設備、安全・法令、費用の多くが**不明**。既存会場が使えるか調べた後の選択肢として表示する。
場所タイプ間の客観ランキングは付けない。**具体的な物件はMVPで提示しない**。

## 6. 常に残す注意
- 子どもの居場所・学習支援：見守り責任者、緊急連絡体制、保護者への説明と同意、安全な開催場所の確認を**別枠で常時表示**。未成年一人で子どもを預かることを促さない。
- other：食事提供、募金、公共空間の利用など、個別の規則・安全条件は未判定。必要に応じて自治体・専門家に確認する。食品を扱う場合の衛生条件等を判断したふりをしない。
- どの活動も公式サイトの情報のみで「利用できる」「許可される」と断定しない。
- 優先3件に収まらない確認事項も「ほかに確認すること」「安全・運営の注意」へアクセスできる。

## 7. 地域情報を案内できる条件
情報はsourceId、URL、運営主体、ページの更新日（判明時）、確認日、対象地域・利用対象、情報種別をもつ。状態：
- verified_reference：公式ページの掲載内容を確認済み。**実際の利用可否は未確認**
- reference_only：参考、詳細は要確認
- not_collected：データ未収録
- unavailable：確認時に利用不可・リンク失効
- demo：架空の説明例（全体・該当項目に架空表示）

初期のリンク候補（2026-11-12公開ページの存在のみ確認）：
1. 高岡市「市民活動相談窓口」 https://www.city.takaoka.toyama.jp/soshiki/kikakuka/2/4_1/5355.html
2. 高岡市「地域交流センター」 https://www.city.takaoka.toyama.jp/gyosei/kurashi_tetsuzuki/juminkatsudo_community_kyodo/2/10190.html
3. 高岡市「サポナビたかおか」案内 https://www.city.takaoka.toyama.jp/gyosei/kurashi_tetsuzuki/juminkatsudo_community_kyodo/5/2/7741.html
実際の対象者、開催内容・時間に対応するかは**施設管理者や相談窓口に確認**する。高岡以外の地区には別地域の情報である旨を表示し、自動で当てはめない。

## 9. 制限
この優先順位は**設計仮説**であり、心理学・法令に基づき検証済みの優先順位ではない。活動経験者・専門家・利用者によるレビュー後に改訂する。ユーザーが最優先アクションを別の行動へ選び直す機能はShould。
