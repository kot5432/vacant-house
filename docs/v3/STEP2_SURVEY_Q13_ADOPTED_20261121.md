# STEP2｜Q13 A案の正式採用（2026-11-21）

- **質問文**：「イベントの企画・準備で、既存の情報だけでは分からなかったことがあれば教えてください。」
- **回答形式**：任意の短文自由記述（段落形式でもよいが、長文を求めない）。氏名、メールアドレス、他人の個人情報、非公開の団体情報などを書かないよう注意を添える。
- **表示対象**：Q12で「一部足りなかった」「ほとんど得られなかった」を選んだ回答者のみ。
- **目的**：Q10の選択肢では捉えられない具体的な不足を、回答者の言葉で把握し、準備全体像・優先順位・公式情報のどこに改善余地があるか検討する。
- **注意**：自由記述は提出必須にしない。回答を需要の代表例として扱う際は、個人が特定される内容を公開しない。
