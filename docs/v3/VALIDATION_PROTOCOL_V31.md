# 需要と独自性を確かめる検証プロトコル v3.1
2026-11-12／**これから行う調査・比較の設計。参加者募集、調査配布、実施、同意収集、アプリ実装は行っていない。**

## 目的
「富山県で新しく非営利の地域活動を始めたい個人・小規模チーム」が、既存サイト・汎用AIでは解決しにくい**活動準備のボトルネック**に直面し、本アプリの「地域の確認条件→相談内容」整理で次の行動が明確になるかを調べる。

## ステップA：実際の需要を聞く（プロダクトの説明前）
募集候補：**個人4人程度、立ち上げ前の小規模チーム4組程度**。活動の種類・背景を偏らせず、子どもの居場所と地域交流イベントの両方を含む。**少人数の探索であり、地域の需要人数や普及率を測るものではない**。

質問（過去の行動を優先）：
1. 始めたい活動は何で、いつまでに行いたいですか。
2. 実際に最後に行った準備は何で、いつ・どこで止まりましたか（行動の具体例）。
3. 活動開始を止めた**最大の障壁を本人の言葉で**教えてください。場所、参加者、協力者、資金、制度、時間等は後から分類。
4. 既に試した検索・サポナビ・相談窓口・学校・AI等は何ですか。どの答えは得られ、何が残りましたか。
5. 「誰に何を聞けば動けるか」は、今わかりますか。そう判断した理由は何ですか。
6. 施設・相談先の条件を間違って理解したことがありますか（言葉や画面を見せる前に聞く）。
7. 本当は場所探しではなく参加者募集や資金不足で止まっている場合、そちらを記録し**場所ナビへ無理に誘導しない**。

記録：匿名ID、活動の種類、個人/チーム、実際にした準備、障壁の種類、既存手段、改善されると嬉しい具体的な情報。実名や具体的な子どもの情報、実在する空き家所在地は記録しない。

## ステップB：開発前でも可能な紙/文章プロトタイプ比較
**同じ一般的なタスク**で以下を比較する。いずれも実際に予約・問い合わせはしない。
- A：高岡市のサポナビ/市民活動相談窓口/地域交流センターの公式情報のみ。
- B：既存の汎用検索やAIで自由に調べる。
- C：v3.1の**画面を文章・紙で模した結果カード**（最初の一歩、公式出典、注意、相談文）。
別々の参加者に異なる順番で提示し、前の条件の学習が次に影響したことを記録する。「自作のアプリだから良いと思うか」ではなく**実行できる行動**で比較。

### 2つの共通シナリオ
1. 「高岡の未成年者だけの企画チームが、子ども向けの体験会を開きたい。地域交流センターを検討」→**2026年1月改定の未成年者のみでの利用不可**を適切に確認できるか。大人が関われば自動許可と誤解しないか。
2. 「非営利の交流会を初めて行う小規模チーム。場所・人数・時間・相談内容が未整理」→自分の状況に合う準備の順序・窓口・確認質問を具体化できるか。

## ステップC：観察する5項目
| 項目 | 記録方法 | 合格の判断（設計上の目安） |
| --- | --- | --- |
| 実在の困りごと | プロダクト説明前のエピソード | 少なくとも複数の独立した具体例がある |
| 最初の一歩の明確さ | 「何を、誰に、どう確認する？」を自分の言葉で回答 | 利用前より具体化。単なる「調べる」では不足 |
| 地域の条件への気づき | 公的サイトのルールと確認結果を照合 | 未成年利用制限を見落とさず、予約保証と混同しない |
| 既存手段からの追加価値 | A/B/Cの行動の正確さ・到達時間・本人の主観を比較 | Cにのみ有益な情報または明確な確認漏れ防止が見られる |
| 行動の現実性 | 相談先・実行への障壁と安全を確認 | 使えない施設、未承認団体、適格でない助成制度に誘導しない |

**重要：**少人数で5人が「使いたい」と言っただけでは需要証明ではない。計測結果は人数/条件/失敗例とともに、限定された範囲で説明する。

## ステップD：進む／修正する／止める
- **進む**：具体的に困った人が複数確認され、既存手段では見落とした地域の条件や確認質問を適切に把握でき、本人が次の行動を具体化する例がある。
- **修正する**：課題はあるが、この案内では一歩を進められない。たとえば仲間や参加者の確保が主因なら別解法を検討。
- **止める／別テーマへ**：実際に使う場面がほぼない、既存の相談窓口だけで十分、条件表示が誤解や危険な行動につながる、出典更新を運用できない。

## ステップE：公開前の整合確認
公的資料の掲載日時・URL・利用条件を再確認。公式情報の転載範囲・ライセンスを確認。外部通信やブラウザー内の入力取扱いを明記。未成年者が関わる聞き取り・子ども向け活動の実施にあたっては、学校・保護者・適切な成人責任者などとの必要な同意と安全確認を行う。
