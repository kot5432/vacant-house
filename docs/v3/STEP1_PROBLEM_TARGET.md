# STEP 1｜ターゲットと課題の最終確定（2026-11-13）

> **ユーザーが選択した方針**：A「活動の始め方・手続きが分からない」＋**「単発・小規模のイベントや体験会を中心にする」**。この決定が現在のSTEP1の正本。先行する「継続的な居場所・学習支援全般」や旧所有者向け空き家診断と混ぜない。

## 1. ターゲット（決定）
**富山県、とくに高岡市で、初めて単発・小規模の非営利イベントや体験会を企画・主催しようとしている個人、または立ち上げ前の小規模チーム。**

- 活動のアイデア・内容は**ある程度決まっている**が、まだ初回開催に至っていない。
- 活動の準備・施設利用条件・相談先の調べ方に慣れていない。
- **一人でも利用可能**。NPO法人や団体登録は不要。学生だけでなく地域住民・社会人も含む。
- **初期の対応地域は高岡市**。富山県全域の施設・制度に対応しているとは主張しない。
- **「小規模」**は初期設計の主な利用イメージであり、人数の固定上限は需要・運営条件の検証まで決めない。

## 2. 中心課題（決定）
**やりたい活動は決まっているのに、初回開催までに必要な準備や手続き、誰に何を確認すべきかの全体像と順番が分からず、最初の具体的な行動を決められないこと。**

3つの内訳：
1. **全体像が不明**：初開催のための準備・確認事項が何か分からない。
2. **順番が不明**：何を先に決める／確かめるべきか判断しにくい。
3. **手続き・確認先が不明**：その人の活動条件で必要な施設利用条件や相談先が分からない。

**課題の存在と規模は未検証の仮説**。利用者の実際の経験によって変わる可能性がある。

## 3. 5W1H
| | 定義 |
| --- | --- |
| Who | 非営利の単発・小規模イベント／体験会を初めて主催する個人・立ち上げ前の小規模チーム |
| What | 準備や手続きの全体像と順番、相談相手や確認事項が分からず、一歩目を決められない |
| When | やることを考えてから**初回開催の準備段階**。とくに次に何をするか迷ったとき |
| Where | 富山県を将来の対象地域とし、**初期の具体的な案内は高岡市**に限定 |
| Why | 活動の種類・人数・開催場所・担当者で準備の確認事項が変わり、情報源が複数あるためと考えられる（未検証） |
| How | 活動・現在の準備状況から、必要な準備の全体像、**優先する最初の確認事項**、根拠のある公的情報、相談する相手・質問を整理する（STEP2で具体的な製品価値を検討） |

## 4. 対象とする具体例（すべて架空）
- 個人が初めて開く**地域交流の単発イベント**。
- 数人の学生が企画する**子ども向けプログラミング体験会（単発）**。
- 小規模チームが企画する**地域の体験ワークショップ（単発）**。

**子どもの居場所を継続的に運営することや、毎週の学習支援教室、子ども食堂の立ち上げ・運営**は初期対象外。後で対象に広げるかは別途検討。子どもが参加する単発体験会については見守り責任者や安全・保護者との連絡等を確認する。

## 5. できること／直接は解決しないこと
- **直接支援する**：準備の見通しを立てる、抜けている確認事項を整理する、どの順に何を調べ/相談するかを具体化する。
- **直接解決しない**：仲間を実際に集める、資金を提供する、参加者を集客する、会場を予約/確保する、許可を得る、イベント開催や地域活性化を保証する。
- 他の地域の制度を高岡市の資料から自動推定しない。空き家は必須ではない。

## 6. ターゲット外
- 単に既存の活動へ参加したい人、何をやりたいか全く決まっていない人。
- すでにイベントを多数開催している主催者の運営管理。
- 営利の開業・店舗・カフェ運営、住宅・移住、旧空き家所有者向け6用途診断。
- **継続的な活動拠点の運営や長期的な子どもの居場所づくり**。これらは従来の検討例で、現STEP1のMVPには含まない。

## 7. 決定の性質と次
- **決定済み**：中心課題A、単発・小規模イベント／体験会、個人も小規模チームも対象。
- **STEP2もユーザーが確定（2026-11-13）**：中心価値は**初回開催の準備の全体像と本人の状況に合う優先順位**。地域の公式条件・最初の具体的な一歩はそれを支える要素。詳細は[STEP2の正本](STEP2_VALUE_DIFFERENTIATION.md)。
- **保留**：実際の利用需要の大きさ、具体的な参加人数の上限、実利用者の検証。聞き取りはユーザー指示により後回し。
