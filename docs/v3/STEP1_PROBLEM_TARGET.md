# STEP 1｜ターゲットと解決課題の定義（2026-11-13）
**現行v3.1の開発前設計・優先する前提。実際の利用者からの需要は未確認。**
履歴の「空き家所有者向け診断」や「子ども支援団体だけを対象とする案」は採用しない。

## 30秒で説明する
**誰**：高岡市周辺で、初めて非営利の地域活動を企画・開催したい個人または立ち上げ前の小規模チーム。**団体登録やNPO法人格は不要**。
**課題**：活動内容は決まっているのに、自分の条件で必要な手続き・確認事項・相談先が分からず、最初の具体的な行動を決められない。
**解決策**：活動と準備状況から「何を／誰に／なぜ確認するか」を出典付きで示し、相談前の情報と質問を整理する。

## 5W1H
| 項目 | 定義 |
| --- | --- |
| Who | 富山で初めて非営利活動を主催しようとしている個人／小規模チーム。まず高岡市で内容・公式情報を扱う |
| What | 準備手順・条件・相談相手が明確でなく、初めの一歩を決められない（仮説） |
| When | やることが決まってから最初に開催するまで、とくに調べ始めたのに先へ進まない時点 |
| Where | 本人の生活圏／高岡市を最初の実証地域とする（市外ユーザーには地域固有情報を適用しない） |
| Why | 活動・人数・時間・協力者・会場の状況で確認事項が変わり、情報が複数の窓口等に分かれるため。**本人の実態は未検証** |
| How | 条件入力→障壁の選択→確認カード→公式情報→相談質問の整理。実際の会場予約や仲間探しは行わない |

## 2つの代表的ユーザー像（**架空**）
1. **個人**：地域で少人数の交流会を開きたい。企画内容は決定。協力者や会場の相談先が分からない。
2. **学生チーム**：子ども向け体験会を開きたい。場所が必要だが、高岡市地域交流センターの利用制限、責任者・見守り体制を確かめていない。

特定の活動を選んだからといって「地域需要あり」「開催すべき」と言わない。学習支援・子どもの居場所は**最初の具体例**であり、利用者をその団体に限定しない。

## 直接解決できる問題と、できない問題
**直接扱う**：確認漏れ、必要な質問が整理できない、複数の公式情報の見分けがつかない、相談前に準備内容がまとまらない。
**直接は扱えない**：仲間・参加者・資金の実際の確保、会場の予約、物件の紹介、活動そのものの運営、開催の成功、子どもを安全に預かることの保証。
※困りごとが「人手・費用」でも相談内容の整理はできるが、それらが獲得できたとみなさない。

## 採用する範囲の判断
- 初回開催前を優先。すでに日常運営している団体の管理は対象外。
- 活動が具体的に決まっていない人向けの趣味・ボランティア参加診断は対象外。
- 営利の開業、飲食許認可の判定、住宅・移住、空き家所有者診断は対象外。
- 地域交流・非営利ワークショップを一般例、子どもの居場所・学習支援を安全確認の重点例にする。

## この仮説を撤回する条件
実際の当事者が活動開始時に困っていない／準備の情報は既存の市の窓口等だけで十分／困りごとは人材・資金の獲得そのもので情報整理に価値がないと判明した場合、ターゲット・解決課題を見直す。

**状況**：チームの開発前の設計方針として具体化。利用者への聞き取りは指示により後回し。
