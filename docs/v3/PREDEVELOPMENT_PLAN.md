## 絶対に混ぜない3つの層
- **現行v3.1（このプロジェクト）**：非営利地域活動の初回開催準備。個人/小規模チームが主対象。次の具体的な確認が価値。
- **旧v2（過去の検討）**：所有者から活動希望者へ移した時期の、場所タイプ別の簡易診断と営利を含む幅広い活動分類。**現行ではない**。
- **旧v1（過去の検討）**：空き家所有者のA/B分類・6用途診断。**現行ではない**。

## 今やること／意図して保留すること
**今進める**：課題を一文にする、価値の差別化を明確化する、機能を削る、情報源と安全上の留保を整える、画面と架空シナリオの整合レビュー、コンテストで説明可能な形にする。
**保留（ユーザーの指示）**：利用者への直接聞き取り・アンケート配布・対外的な相談・比較実験。
**未指示なので行わない**：アプリの実装、実行テスト、デプロイ・公開、実際の予約/申請。

## 着手前に残る判断
1. **チームメンバー・担当・作業可能な時間・レビュー体制**の確定。
2. **地域情報を誰が更新するか**と、確認できない古い条件を抑止する運用。
3. **実ユーザー需要を未検証のまま制作に入るリスクを受け入れるか**（聞き取りは後回しなので未解決）。
4. MVPのデモをどの活動例で見せるか（候補：子ども向け体験会・個人の地域交流会）。
5. コード着手は別途ユーザーが指示するまで行わない。
