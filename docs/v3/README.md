## このプロダクトを使うのは誰？
高岡市周辺で、やりたい**非営利の地域活動**が決まっているが初回開催の準備で止まっている**個人・立ち上げ前の小規模チーム**。NPO法人への所属は不要。

## 何を提供する？
本人の今の障壁と準備状況を整理し、**高岡市の実際の施設利用条件や公式相談先に沿って「誰に何を確認し、まず何をするか」**を具体化。相談のための下書きをコピーできる。相談窓口や施設予約は**既存のサービスに接続する**のであり、代わりに実行しない。

重点の例は、子どもの居場所・学習支援、非営利の体験会・地域交流。空き家は必要なときの選択肢の一つであり、物件を探したり予約したりしない。

## 現状の真偽の区別
**確認できた**：高岡市の相談・施設予約サービスとその公式情報、一部施設の利用条件、他地域の団体立ち上げ時の障壁、子どもの居場所への希望。  
**仮説**：本人の「困りごと」を聞いてから地域の具体的な確認方法へ結びつけると、既存検索・窓口や汎用AIより次に動きやすくなる。  
**未実施**：活動希望者への面談、紙プロトタイプ比較、実装、テスト、外部連絡、施設の予約、デプロイ、応募。

## 安全と制限
未成年のみの高岡市地域交流センター利用は2026年1月改定の公式注意で認められていません。ただし**実際の利用可否は管理者の判断で別確認**。学校・保護者や信頼できる成人等への相談を案内し、条件を回避することは促さない。子ども向け活動の見守り責任・安全も個別確認する。

## 開発可否
まず小規模な実需要の聞き取り・比較で独自の価値を検証。**設計完了は需要証明でも開発の承認でもありません。**
