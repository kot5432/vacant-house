# 現行設計 v3.0 — 地域活動の「はじめの一歩」をつくる

> **2026-11-12の新方針／設計のみ・未実装・需要未検証**  
> **ここだけが現行設計の入口です。** docs/直下のv1・v2資料とPROJECT_CONCEPT.mdの第1〜53章は**検討履歴（非現行）**です。旧「空き家所有者向け6用途診断」やv2「営利活動を含む場所3タイプ診断」を現行MVPに混ぜないでください。

## ひとことで
**「地域のためにやりたいことは決まった。でも何から始めればいいか分からない」という個人・立ち上げ前のチームが、活動の条件・困りごとを整理し、相談先と最初の具体的な一歩を決めるWebアプリ。**

## 優先する対象
- 富山県（実証は高岡市）の、**非営利の地域活動を自ら新しく始めたい個人／立ち上げ前の小規模チーム**。
- **法人格や団体への所属は不要**。一人・チームで案内を分岐。
- 最初の実証活動：子どもの居場所づくり／学習支援。次の一般例：地域交流・ワークショップ。
- 既存団体の運営管理、ボランティアへの参加先検索、営利の開業支援は今回のMVPの対象外。
- 具体的な活動内容が全く決まっていない人への興味診断は対象外。

## 利用者が持ち帰るもの
1. **活動準備の整理**（決まったこと／まだ決まっていないこと）。
2. **優先する次の一歩**（まず何をすべきか、理由、実施方法）。
3. **高岡市の公式の支援・施設情報につながる確認先**（出典付き、活動許可の保証なし）。
4. **相談用の文章ひな形**（入力内容に沿った項目を含み、コピー可能。送信しない）。

空き家は**選択肢の一つ**。現実に必要かを判断する前に、既存施設や活動団体の拠点を確認。**実物件検索・所有者マッチングなし**。
