## 活動データを「参加一覧」に掲載するための証拠
| フィールド案 | 根拠/扱い |
|---|---|
| `activityId` | 版の中で安定し、一意。主催EventRecordのeventIdとは別 |
| `title, organizer, municipality, topicTags` | 個別活動の公式一次ページで確認。市町村・タグの全enumは未承認 |
| `sourceUrl, sourceCheckedAt, evidenceNotes` | 外部リンクの安全性、どこに何が書いてあったか、確認時刻 |
| `schedule, location, eligibility, fee, registration, duration, preparation` | それぞれ`confirmed/unknown/not_applicable`を別に記録。未記載→無料や不要にしない |
| `firstTimeWelcome, soloAllowed` | 原文で裏付けがないならunknown、利用者の属性を推測しない |
| `recruitmentState, recruitmentCheckedAt` | `confirmed_open/confirmed_closed/unknown`は**確認時点の記録**。残席・受付保証ではない |
| `reviewStatus, reviewedBy, catalogVersion` | 別人審査・掲載停止・変更追跡。実在するレビュアー名は未割当 |

## 公開できるかの判断
1. **個別活動と一意の公式詳細URLが存在**するか。団体一覧/イベントポータルは案内先に分類し、個別イベント1件として水増ししない。
2. EがURL・主催者・地域・開催内容・確認日時を台帳に記録。出典にない情報はunknown。
3. AまたはBの別人レビューで、対象/費用/募集/一人参加可否/著作権/掲載表現を照合。
4. 掲載できる個別データのみ`visible`へ。確認保留/リンク切れ/撤回要請/情報相違は`needs_review`または`archived`に変更。
5. 公式URLで最新を確認する一歩を表示。**「現在受付中」を断定しない**。D01の該当0件も正常な状態。

## 高岡の既存候補の位置付け（今回の個別確認は未実施）
- 市の家族/地域情報・図書館の行事ページ：個別日時と条件の確認候補。
- 市社協ボランティア・御旅屋いさま・たかおかSDGs DAYs：索引または複数活動の入口となる候補。
- 競合サポナビたかおか/とやまちむすび：活動を探す導線の比較対象。一次根拠の代用にはしない。

## 情報源が足りないときの安全な縮小
- 個別活動が0件なら「現在掲載できる活動なし」＋確認済み公式索引。未確認活動を仮の掲載件数に混ぜない。
- 未確認の欄は空欄ではなく「情報を確認できていません」。会場の空き、申込資格、行政許可や安全を確約しない。
- **主催施設の公式出典カタログ月末JSTレビュー規則（ADR-011）**を参加募集の`confirmed_open`保証の期限として流用しない。
- 更新責任者・訂正連絡先・掲載元からの要請対応が決まらない場合、一般公開時の活動カードは無理に充実させない。

## E（品質）の担当と検証範囲
- Eはカタログの収集・更新担当候補、PRレビューを調整。AがD01/D02の表示・検索動作を担当。
- Eが作った情報はE自身で承認完結しない。A/Bが一次URLと表現を別人レビュー。
- 公開情報のチェック時刻と、アプリでの評価時刻を区別。毎日監視・自動巡回できると主張しない。
- 参加候補/主催者候補へのヒアリング・既存サイトとの比較は**設計だけ**、結果は未収集。

## 発見時の修正・停止手順
`報告→Eが影響カードの情報を照合→必要なら停止状態のPR→A/Bがレビュー→公開版を更新→出典と対応日時を記録`。公開運用を始めるには本人の担当承認と実装・公開許可が必要。
