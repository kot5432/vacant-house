# STEP2-⑯-②｜回答データ削除期限A案の採用（2026-11-21）

## 正式決定
- 回答原データの保管は、既決のC案「アプリ開発・検証が終わるまで」とする。
- **開発・検証の完了後30日以内に、回答原データを削除する（A案正式採用）。**
- 削除対象はGoogleフォームの個別回答、連携Googleスプレッドシート、エクスポートCSV等の複製、ローカルバックアップを含む。集計して個人を識別できない統計を今後保持する場合、その扱いを配布前に案内する。
- 主担当はE。Eの個人Googleアカウントで管理。回答原文をGitHubにコミットしない。
- 「開発・検証完了」の判断日はEがチームと記録し、そこから30日以内を運用上の削除期限とする。ただし**この相対期限だけでは回答時点に最終日を提示できない**ため、配布前に最終削除日の上限（具体的な年月日）も別途確定し、回答者向け説明文へ明記する。完了が長期化しても無期限保管しない。
- 匿名フォームでは個別回答を特定して撤回・削除することが難しい場合がある。回答者への説明にはその限界と問い合わせ方法を含める。

5. プレビューでスマホ・PC、所要時間、回答送信後の表示を確認してから配布先と期間を決める。
