# STEP2｜アンケートQ5 A案採用・Q6検討（2026-11-21）

## 正式決定：Q5 参加経験をきっかけに主催したいと思ったか

- **質問**：「地域イベントや活動に参加したことをきっかけに、自分でも何かを企画・開催してみたいと思ったことはありますか？」
- **形式**：単一選択
- **選択肢**：
  1. ある
  2. ない
  3. 地域イベント・活動に参加した経験がない
  4. 覚えていない・回答しない
- **目的**：参加から主催への関心が生じた経験の有無を把握する。主催希望者全員が参加をきっかけにしたと仮定しない。
- **Q3との整合**：Q3-2（過去半年の参加）とは期間が異なる。Q3-2が「ない」の人でも過去の参加経験を持ち得るため、Q5の「参加経験がない」はこれまで一度も参加したことがない意味と明記する。Q3-2だけを根拠にQ5を非表示にしない。
- **分析**：「ある」と回答した割合は調査対象者内の記述統計であり、参加が主催意欲を引き起こす因果関係の証明ではない。主催意欲がない人や参加経験がない人の回答も保持する。

## 次の検討：Q6（正式採用前）

**目的**：参加側の機能が解決すべき困りごとを、実際の経験から把握する。現在のサイト・SNSで問題なく探せている人の声も収集する。

- **A案（推奨）**：「これまでに地域イベント・活動を探した際、情報を見つけたり参加を判断したりするうえで困ったことはありましたか？」（単一選択：よくあった／ときどきあった／ほとんどなかった／まったくなかった／自分で探した経験がない／覚えていない・回答しない）。後続Q7で具体的に何に困ったかを聞く。
- **B案**：「イベントを探す際、どの情報が分からないことが多かったですか？」といきなり複数選択。課題の種類は取れるが「困らなかった」経験との区別を工夫する必要がある。
- **C案**：「イベントを探す際、どこで情報を調べましたか？」（複数選択）。既存の代替手段は分かるが、困った経験を直接把握できない。

Q6はまだ未決定。質問番号・分岐はフォーム全体を統合する際に確定する。実際の困りごとの探索を優先し、アプリへの賛否を誘導しない。
