# STEP2｜アンケートQ10 A案採用・Q11検討（2026-11-21）

## 正式決定：Q10 企画・開催時の課題を複数選択

- **質問**：「地域イベントを企画・開催する際、困ったこと、または難しそうだと感じることは何ですか？」
- **形式**：チェックボックス（複数選択）
- **選択肢**：
  1. 準備することの全体像が分からない
  2. 準備の順番・優先順位が分からない
  3. 会場探し・予約が難しい
  4. 必要な申請・手続きが分からない
  5. 安全管理について分からない
  6. 予算・費用の見積もりが難しい
  7. 協力者・人手を集めるのが難しい
  8. 参加者募集・周知が難しい
  9. 特にない
  10. まだ考えたことがない
  11. その他
- **対象・解釈**：Q4で企画・開催経験または関心がある人への設問。既に開催した人の「実際に困ったこと」と、準備前の人の「難しそうという予想」は、Q4の回答区分を使って別集計する。Q4の「企画・開催を考えたことはない」「回答しない」は、分岐でスキップする設計を優先。
- **排他選択肢**：「特にない」「まだ考えたことがない」は他と同時選択させない想定。Googleフォームで実現できるかは最終設定時に確認し、難しい場合は分岐・設問構成を調整する。
- **調査目的**：中心価値である準備の全体像・優先順位と、会場・申請・安全・人手・周知の課題を比較し、課題の存在を検証する。質問への回答からMVPの新機能を自動決定しない。

## Q11案（正式採用前）

**目的**：主催側の課題に直面したときに、既存の情報や他者の助けでどう対応しているかを把握する。「困っている」だけでは需要の強さを断定できないため、実際の行動を聞く。

- **A案（推奨）**：「イベントを企画・準備した際、必要な情報をどのように調べたり、困りごとを解決したりしましたか？」（複数選択：自治体の公式情報を調べた／会場・施設へ問い合わせた／経験者・知人に相談した／SNS・検索エンジンで調べた／チェックリスト・手引きを利用した／準備・開催を延期または見送った／まだ準備した経験がない／覚えていない・回答しない／その他）。実際の行動を聞き、**未経験者は「まだ準備した経験がない」**を選べるようにする。後ろ2つは排他の想定。
- **B案**：一番役立った情報源だけを単一選択で聞く。既存の有効な手段を把握できるが、複数の対応や見送りを捉えにくい。
- **C案**：実際に困った場面と行動を任意の自由記述で尋ねる。深い回答が期待できるが負担が増える。

**Q11は未決定**。正式文言・選択肢は利用者が選択してから決める。調査フォーム全体の分岐と3〜5分の回答時間は最後にレビューする。
