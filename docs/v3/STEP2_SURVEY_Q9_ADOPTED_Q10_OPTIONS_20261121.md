# STEP2｜アンケートQ9 A案採用・Q10検討（2026-11-21）

## 正式決定：Q9 情報不足時に実際に取った行動

- **質問**：「地域イベント・活動を探す中で、必要な情報が分からなかったとき、実際にどのように対応しましたか？」
- **形式**：チェックボックス（複数選択）
- **選択肢**：
  1. 主催者・施設の公式情報を追加で調べた
  2. 主催者・施設に問い合わせた
  3. 家族・友人・知人に聞いた
  4. 別のイベント・活動を探した
  5. 参加を見送った
  6. 情報不足に困った経験はない
  7. 覚えていない・回答しない
  8. その他
- **目的**：困った内容（Q7）と、その結果としての探索・問い合わせ・見送り等の行動を区別する。参加を見送った理由が情報不足だけであると断定しない。
- **分岐**：Q6で「よくあった」「ときどきあった」を選んだ人を中心に表示する。「ほとんどなかった」の扱いはフォーム全体の分岐設計で確定する。経験なし・回答なしにQ9を強制しない。
- **排他**：「情報不足に困った経験はない」「覚えていない・回答しない」は他選択肢と同時に選べないようにする。Googleフォームで排他を設定できない場合は分岐・別問化等を検討。
- **正式採用範囲**：質問意図・複数選択・選択肢。フォームの実際の分岐や表示設定は最終レビュー事項。

## 次に検討：Q10 主催側の困りごと（未決定）

目的：初めて地域イベントを企画した人が「何に困ったか」、企画を検討している人が「何に不安を感じるか」を区別して把握する。Q4主催経験段階に従い回答を解釈する。

- **A案（推奨）**：「地域イベントを企画・開催する際、困ったこと、または難しそうだと感じることは何ですか？」（複数選択：準備することの全体像／準備の順番・優先順位／会場探し・予約／必要な申請・手続き／安全管理／予算・費用／協力者・人手／参加者募集・周知／特にない／まだ考えたことがない／その他）。Q4で「考えたことがない」の人は原則分岐でスキップし、経験と予想を集計時に分ける。選択肢の排他扱いを最終調整する。
- **B案**：最も困ったことを一つだけ選ぶ（単一選択）。最優先課題を把握できるが、複合的な準備障壁を見落とす可能性。
- **C案**：最近の具体的な企画経験を短文で記述（任意）。状況は理解しやすいが回答負担が増え、経験がない層の回答が減る可能性。
