# STEP2｜アンケートQ2採用・Q3検討（2026-11-21）

## 正式決定：Q2
- 質問：**富山県内の地域イベント・活動について、あなたに当てはまるものを選んでください。**
- 回答形式：複数選択（チェックボックス）。
- 選択肢：
  1. 富山県内に住んでいる
  2. 富山県内に通学・通勤している
  3. 富山県内のイベントに参加したことがある
  4. 富山県内のイベントに興味がある
  5. いずれも当てはまらない
  6. 回答しない
- **フォーム作成時の注意**：5「いずれも当てはまらない」と6「回答しない」は、ほかの選択肢と同時に選ばない排他選択肢として設定する。利用するGoogleフォームの仕様で排他設定ができない場合は、回答の矛盾を避けるため設問形式を見直す（分割など）。曖昧な回答を勝手に富山との接点ありと解釈しない。
- 目的：正確な住所や居住地を収集せず、県外からの参加関心も含む地域との接点を把握する。
