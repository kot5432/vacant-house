## 3. 記録・レビューとアプリへの反映判断

1. 各施設について`officialUrl / facilityId / category / claim / documentRevision / checkedAtJST / contactAnswer / reviewedBy / status`を別行で管理。未確認欄は空欄にし、「確認済み」にしない。
2. **A：地域交流センター2施設**でR8.1資料の適用可否を比較、**B：別カテゴリ2施設**でその資料を適用しない境界を確認。この4件で十分な違いが見えなければ施設追加ではなく対象仮説を再評価。
3. 公式原ページと管理者回答の食い違いは、確認が取れるまで`needs_review`／施設固有断定停止。
4. 二人目が出典・範囲・表示文言を確認したものだけ掲載候補とする。高岡市のJST月末点検（次回2026-11-30）とリリース前点検を維持。
5. P08は**P2基本（ADR-027）**、P05は参加対象によりADR-003、P01〜P12の順位と本人進捗は変えない。申込・法的要否・安全性を自動確定しない。
