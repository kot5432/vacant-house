# STEP4-オンライン開催の対象範囲｜選択肢比較（2026-11-15）

> **状態：2026-11-15 B案をユーザーが正式採用。** 決定事項は[ADR-002](ADR_002_NO_PHYSICAL_VENUE_SCOPE.md)を参照。以下は決定前の比較履歴。 現行製品は「初めて単発・小規模の非営利地域イベントを主催する人の準備全体像と優先順位」を支援する。旧空き家案から移行した物件・施設マッチング案は対象外。実装・利用者調査は未実施。
> 関連：[入力設計](STEP5_02_HOME_SETUP_WIREFRAMES.md)、[判定表 v1.1](STEP4_RULE_DECISION_TABLE_V11.md)、[ルール契約](RULE_ENGINE_CONTRACT_V1.md)。

## 1. 問題の位置付け

現行U02の会場状態に `no_physical_venue`（物理的な会場を使わない）がある。しかしこの回答だけでは**「完全オンライン開催」「屋外で集まるが施設を使わない」「移動型イベント」等を区別できない**。自動的にオンライン専用イベントと判定してしまうと、入力からは分からない情報を推測してしまう。

そのため、`no_physical_venue`選択時に、P07/P08の物理会場の選定・手続きを非該当とする以外の対応は、MVPスコープの正式判断が必要。

## 2. 3案の比較

| 項目 | A案：物理会場を使うイベント限定 | B案：物理会場なしも限定的に支援（推奨） | C案：オンライン専用の準備プランを実装 |
|---|---|---|---|
| 初期MVPの広さ | 最小 | 小さな追加・既存選択肢を維持 | 大幅に拡大 |
| `no_physical_venue` | U02から除外（または対象外として案内） | **値を残し、オンラインと断定せず一般準備だけ提供** | 追加質問でオンラインを明示判定 |
| P07/P08 | 物理会場が必要な場合のみ | 物理施設の確認は非該当と説明 | 配信方法・利用規約等を別タスク化 |
| P09 | 物理設備・会場環境のタスクのみ扱う | **物理設備のチェックだけ適用外にし、開催形式の不明点を残す** | 配信機材・通信・操作環境に最適化 |
| 特有の安全/プライバシー | 対象外を説明 | **未対応・本人確認が必要と明示** | オンライン固有の確認項目を追加 |
| 判定ルールの開発負担 | 低 | 中（誤案内を防ぐ分岐） | 高 |
| 価値の一貫性 | 物理開催に絞る | 一般準備の全体像を保ちつつ限界を表記 | 対象範囲が広くなりがち |

### 推奨：B案

「物理会場なし」の回答を**オンライン開催と決めつけない**。企画・運営・募集の一般タスクは表示し、P07/P08の**建物・施設に関する部分だけ**非該当とする。P09については「物理会場での備品・設備確認」は非該当とし、代わりに**開催方法・必要な環境について本人が確認する一般事項**を示す案。ただしオンライン専用の通信・配信・参加者認証・個人情報等の固有ルールは提供しない。

この案を採用するときの表示文例：
> 「物理的な会場を使わないと回答されています。施設の予約や設備に関する準備は対象外として表示します。開催形式や必要な環境については、ご自身で確認してください。このプランはオンライン開催固有の手続きを網羅していません。」

**後続のADR-002でB案を正式採用済み。** `no_physical_venue`が屋外活動なども含む場合、屋外利用条件・安全確認が必要になることがあり、P07/P08を丸ごと不要とは判断できない。B案が正確に成り立つよう、U02の選択肢文言をどうするか、確認が必要な可能性がある。

## 3. B案採用前に解消する矛盾

- 「物理会場なし」の現在の値がオンライン専用と同義ではないため、単純に「施設手続き一切不要」と言わない。公園・道路等の利用条件がある場合も想定される。
- 必要なら既存Q4に「会場の使用形態が未定」「オンライン開催（明示）」「施設は使わないが現地開催」などの詳細を追加する代わりに、MVP範囲を縮小する選択肢もある。
- 現行の基本6問を増やさないことが採用済みのため、質問数を増やす場合も**基本質問数は6のまま**でQ4の選択肢・条件付き質問で対応する必要がある。
- 選択肢の追加・変更は既存保存データの`schemaVersion`移行や判定ルール版を伴う。
- 個別の許可・安全・施設利用条件を確認済みと自動表示しない。

## 5. 比較時点の判断課題（正式決定はADR-002）

「初期MVPは物理会場を使うイベントに絞る（A）」か、「物理会場なしの一般準備も限定的に案内する（B）」か、「オンライン専用まで詳細に扱う（C）」か。**B案を推奨するが、屋外現地開催とオンラインの意味の違いをUIで説明・適用範囲を限定する必要がある**。

**決定済み：** 基本6問を維持し、建物の会場に限った子項目のみ非該当、親P07〜P09は開催形式・場所の要確認を残す。詳細はADR-002。
