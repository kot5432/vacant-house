# STEP2｜アンケートQ6 A案採用・Q7検討（2026-11-21）

## 正式決定：Q6 イベントを探す際に困った経験の頻度

- **質問**：「これまでに地域イベント・活動を探した際、情報を見つけたり参加を判断したりするうえで困ったことはありましたか？」
- **形式**：単一選択
- **選択肢**：
  1. よくあった
  2. ときどきあった
  3. ほとんどなかった
  4. まったくなかった
  5. 自分で探した経験がない
  6. 覚えていない・回答しない
- **調査目的**：参加側の実際の課題の存在と頻度を把握。困っていない人、検索経験がない人の回答も残す。「アプリが欲しいか」を先に聞いて誘導しない。
- **整合**：Q3-1は「過去半年」の検索経験、Q6は「これまで」の経験で期間が異なる。Q3-1で半年以内に探していない人も過去に探したことがあればQ6へ回答できる。Q3-1「ある」かつQ6「検索経験なし」等の不一致を、回答者の不正と断定せず全体レビューで文言・期間を調整する。
- **Googleフォーム分岐案**：Q6の経験なし・回答なしの人に、具体的な困りごとを強制しない。「よくあった／ときどきあった」の回答者にQ7を示すか、Q7へ「困らなかった・該当なし」を設ける。Googleフォームのセクション分岐可否・設問数を実際のフォーム作成前に確認する。未設定の分岐を実装済み扱いしない。

## 次の検討：Q7（未決定）

**目的**：Q6で困ったと答えた人が、どの段階・情報で困ったのか具体的に特定し、参加側D01/D02の改善優先順位を考える。

- **A案（推奨）**：「イベントを探したり参加するか判断したりするとき、具体的にどのようなことで困りましたか？」複数選択（イベント情報そのものが見つからない／開催日時・場所が分からない／対象年齢・参加条件が分からない／費用が分からない／申込方法・期限が分からない／初参加や一人参加の可否が分からない／情報が古い・募集中か不明／その他／特に困らなかった）。該当がない人に無理な選択を強制せず、排他項目の整合性を検討する。
- **B案**：もっとも困ったことを一つだけ選ぶ。優先課題は把握しやすいが複合的な障壁を捉えにくい。
- **C案**：最近困った具体的な場面を自由記述する。実際のエピソードは得られるが回答負担と個人情報記載リスクが上がる。

**Q7は未採用**。設問文・選択肢と分岐はユーザー判断後に確定し、全体最終レビューでGoogleフォームに適合させる。
