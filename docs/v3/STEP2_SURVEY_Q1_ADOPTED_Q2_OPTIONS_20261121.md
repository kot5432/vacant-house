# STEP2｜アンケートQ1採用とQ2検討（2026-11-21）

## 正式決定：Q1
- 質問：**あなたの現在の立場を教えてください。**
- 形式：単一選択
- 選択肢：高校生／高専生／大学生・短大生・専門学生／社会人／その他／回答しない
- 目的：参加・企画の困りごとの違いを属性別に集計する。学校名、勤務先、厳密な年齢は収集しない。
- 選択肢「その他」「回答しない」を残す。回答属性だけでイベントに参加できるかを判断しない。

## 次の検討：Q2（正式採用前）
- 確認したいこと：回答者が富山県内の地域イベントと接点を持つ人か。ただし正確な居住地・住所は必要ない。
- 推奨案A：「富山県内の地域イベント・活動について、あなたに当てはまるものを選んでください」（複数選択：富山県内に住んでいる／富山県内に通学・通勤している／富山県内のイベントに参加したことがある／富山県内のイベントに興味がある／いずれも当てはまらない／回答しない）。排他選択肢の実装に注意。
- 代替案B：居住地域だけを大まかに問う（県内／県外／回答しない）。県外から参加する層を十分捉えられない。
- 代替案C：地域を聞かず、活動経験の質問へ進む。サンプルと富山との関連が判別しにくい。
- Q2は**まだ決定しない**。ユーザー選択後に正式設問へ。

## 既決と未実施
- Googleフォーム方式、対象＝高校生・高専生＋大学生・社会人。
- 回答任意、氏名・メールアドレス収集なしを基本とする。
- フォーム実作成・配布・回答分析は未実施。アプリ実装・テスト・公開なし。
