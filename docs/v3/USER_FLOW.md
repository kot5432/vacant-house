# 画面設計 v3.0：次の一歩を主役にする
2026-11-12／**文章ワイヤーフレームのみ・UI画像やコードは未作成**。現行フローは旧所有者向け建物フォームと無関係。

## 基本ナビゲーション
Home → ステップ1「どんな活動を、誰と？」 → ステップ2「決まっていることは？」 → 結果「まず、これをしよう」 → （任意）場所の選択肢・公式参考情報 → 相談文を確認してコピー。
戻る場合に入力保持。主要操作は各画面に原則1つ。320px以上の幅で縦配置、文字拡大とキーボードで操作できるように設計。

### U01 Home
```text
地域でやりたいことを、最初の一歩へ。
「何を始めたいか」は決まっているけれど、
仲間・場所・準備がまだなら、今やることを整理しましょう。
[始める]
[架空の例で体験]
※会場の利用・参加者・協力者が決まることは保証しません。
```

### U02 ステップ1/2「やりたい活動と今の状態」
```text
活動は決まっていますか？
[子どもの居場所・学習支援] [地域交流・ワークショップ]
[その他の非営利地域活動]
今はどんな状態？（必須）
[一人で始めたい] [仲間とチームで準備中]
どんなことをしたい？（任意） [　　　　　　　]
※入力文は自動でAI判定しません。
[次へ]
```
選択が未完了なら項目直下に説明。団体登録・名称は求めない。**子ども食堂、営利の開業などは細かな判定の対象外**であり、その他の一般的な相談案内にとどまる。

### U03 ステップ2/2「決まったことを確認」
```text
相談・協力できる人は？ [いる／探している／不明]
活動の責任者は？      [いる／相談・調整中／不明]
活動する地区は？      [高岡市内の候補/まだ未定]（任意）
開催は？  [単発／継続／未定]　時期・時間帯［任意］
人数の目安は？［正の整数／不明］
会場に必要なもの［机・椅子／電源／通信／静かな場所／その他］
[次の一歩を見る]
```
入力負担を減らすため「地区・日時・人数・設備」は任意。人数0以下/小数などは入力エラーで確認。未選択は「不明」で進める。

### U04 結果「まず、ここから」
```text
子どもの居場所づくりを始めたいあなたへ
[活動の準備状況：すでに決まったこと／まだ未定]
[最優先] まず、責任者や相談できる人を確認しましょう
理由：子どもが参加する活動には、継続して見守れる運営体制の確認が必要です
[最初の行動] 活動内容を整理し、相談できる成人・既存の地域活動団体に相談する
[確認方法] 地域の市民活動相談窓口等の公式案内を確認する
［公式の参考先を開く］
---
[次にできること：希望人数・日時の整理]
[その次：利用できる会場条件の確認]
［場所の選択肢を比較する］
［相談文を作る］
※案内は一般的な準備の目安で、団体の協力意思や施設利用を保証しません
```
**結果の先頭は最優先の一歩**。場所タイプ3枚を最初に並べない。カードには理由と未確認の項目を表示、ユーザーに適合スコアを見せない。

### U05 「場所を考える」（任意）
```text
場所はどう考える？
[既存の公共・地域施設] → 利用対象、開催時間、設備、申込方法、定員
[既存団体・民間の活動拠点] → 共同利用、費用、時間、関係者の承諾
[空き家] → 所有者の意思、契約、改修費、安全と法令
「まず既存施設を調べる」→ [市の公式施設案内]
※具体的な空き家・会場の予約候補を探す機能ではありません。
```
施設が既に十分なら空き家へ誘導しない。出典のない施設を名指ししない。

### U06 「相談の準備」
```text
相談したい内容をまとめました
相談先の種類 [市民活動相談窓口/施設管理者/既存活動団体]
件名例: 地域活動を始めるための相談
「地域で○○の活動を検討しています。
個人（または準備中のチーム）で、参加人数は○○人程度です。
開催時期は○○を希望しています。
活動に必要な条件や利用できる場所について、
どのように確認すればよいかご相談したいです。」
[文章をコピー]
[活動条件を修正]
※送信されません。個人情報や実施の保証は追加しないでください。
```
文章は本人が編集し確認してコピー。未入力の項目は「未定」と明示し、勝手に推測しない。電話番号/メール/氏名の入力欄はMVPに設けない。

## 2つの通し例
**A：個人／子どもの学習支援／協力者なし・責任者未定** → 最優先「安全・運営について相談できる人を確認」、次「対象人数/曜日を整理」、その後「既存施設の使用条件を調べる」。大人の責任者が確保されることをアプリが保証しない。

**B：3人のチーム／非営利ワークショップ／責任者あり・人数/日時決定** → 最優先「既存の地域施設の利用条件・時間帯・予約方法を確認」、次「費用と必要備品の確認」。空き家を優先しない。

## 例外
- **地区未選択**：特定施設の推奨はなく、公式一般窓口と確認の方法を案内。
- **参考リンクが切れている/条件不明**：リンク案内を保留。公式窓口の一般案内へ縮退。
- **その他の活動**：活動固有の安全・法律判断なし。個別に確認が必要と明示。
- **架空デモ**：全画面で架空を示し、実際の利用者情報に見せない。
- **子ども関連**：子どもの見守り、責任者、保護者との連絡等の確認を固定注意として示す。未成年が単独で子どもを預かる行為を推奨しない。
- **調理/食事の自由記述**：自由記述を自動判別しないため、食事提供の個別手順/許可案内を出せないことを明示し、「その他」に一般的相談として誘導。

## 初見テストの問い
1. このアプリでできること・できないことを説明できるか。
2. 個人で仲間未定でも使えるか。
3. 「最優先の一歩」が何かを自分の言葉で言えるか。
4. 相談用の文章で、確定情報・未定情報が混ざっていないか。
5. 公的な情報リンクを見て「使えると確定した」と誤解しないか。
6. 320px・キーボード・入力修正時に正しい表示か。
