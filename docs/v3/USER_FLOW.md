## U04 結果（最初の一歩を主役に）
1. **「今の障壁：場所の条件が分からない」**（本人が選んだ場合。選択なしは不明と表記）。
2. **まずこれを確認**：1件の事前確認カード。
   - 誰に／何を聞くか
   - なぜ最初か（選択・不足・公的ルールのどれが根拠か）
   - 最初の行動（抽象的な「調べる」だけで終わらない）
   - 公式リンクと確認日（なければ「一般的な確認事項」）
   - まだ確認できていないこと、安全・運営上の注意
3. その他の行動最大2件。安全上の必要な確認は別領域に常時表示。
4. [場所について詳しく確認] [相談文を作る] [入力修正]

## U05 会場・地域の確認（必要な場合のみ）
- **既存公共・地域施設**：利用対象、人数、活動の種類、利用曜日、施設管理者の承認、設備、料金を要確認。
- **既存団体の活動拠点・民間会場**：相手の承諾、使用条件・費用が未確認。
- **空き家**：所有者同意、契約、建物安全、整備費、活動の可否がすべて別確認。既存施設で足りるなら積極的に勧めない。
- 結果の後に地域交流センターの利用意向や利用者構成を**変更する場合は、最初の事前確認カードと相談文の質問を再計算**する。入力の値と結果の前提を一致させる。
- **未成年のみ**：高岡市の地域交流センター利用上の注意（R8.1改定）では未成年者のみの利用が不可と明記。公式根拠とともに、学校・保護者・信頼できる成人・施設管理者への相談を促す。**成人が関われば必ず許可という意味ではない**。
- 空き状況のオンライン確認・利用申込みは既存の公式サービスへ案内し、アプリで予約はしない。
- [結果へ戻る] [相談文を作る]

## U06 相談用の準備文
「○○という非営利活動を、個人／準備中チームで検討しています。参加人数は○○、希望時期は○○です。今は○○の確認で困っています。○○の活動内容・利用条件について確認したいです。」
- 公式資料にある具体的注意を相談の質問に反映（例：未成年者のみの利用条件）。
- 未入力は「未定」と表示。入力した内容を本人が編集・確認してからコピー。
- **自動送信・個人情報の入力要求・裏側での外部AI解析はしない**。

## 通し例
**例A（架空）**：高校生3人、子ども向け体験会、困りごと=会場、センターを検討、未成年者のみ→最初の一歩は責任体制・施設利用条件の確認。公式案内と相談文に「未成年者のみでの利用不可、管理者の許可が必要」を明示。子どもの見守り責任者の確認は別枠で常に表示。

**例B（架空）**：成人を含む小規模チーム、地域交流、会場未定・人数未定→最初に参加人数・希望日時を整理し、地域交流センターの公式利用条件を調べる。成人がいても自動的に許可されるとは表示しない。

## 机上レビューで追加した整合条件
- 「センター検討中＋未成年者のみ」という前提をU03で入力した場合、結果の最初のカードはその条件を見落とさない。
- 高岡市地域交流センターを**明示的に検討していない**なら、当該施設の利用不可を自分の活動全体の結論として断定しない。
- 高岡市以外を希望していても、本人が明示的に高岡市の地域交流センターを検討しているなら**その施設に限った参考条件**として提示できる。その場所へ通える、利用できるという結論は出さない。
- 正確な年齢や個人情報の入力を求めず、学生・個人を不当に排除しない。
- 入力変更と戻る操作で結果・相談文が更新される。
