# 現行製品仕様 v3.1 — 地域活動の事前確認ナビ
更新：2026-11-12。**設計のみ／コード・利用者調査・検証テストは未実施**。本書と同じ `docs/v3/` 内の v3.1 資料が現行の基準。旧版はGit履歴に保存。

## 1. 誰の何を解決するか
**第一対象**：富山県・高岡市周辺で、やりたい非営利の地域活動が決まっているが**まだ初回開催に至っていない個人・立ち上げ前の小規模チーム**。NPO法人や既存団体への所属は不要。

**困りごと（未検証の仮説）**：「会場・協力者・準備・手続きのうち、どこで止まっているか、最初に誰に何を確認すればよいかが分からない」。本アプリは「人やお金を見つける」「会場を予約する」ことを直接解決しない。

**提供する中心価値**：**自分が困っていることと未確認事項を整理し、高岡市の実際の施設・支援条件を参照しながら、最初に確認する相手・質問・一歩を決められる**。

## 2. 調査で判明した限界
高岡市の中高生の49.8%が自由に過ごせる施設を望むという調査は**居場所への社会的希望**であり、開催したい人やアプリ利用者の割合ではない。愛知県東海市の登録団体81件の2024年振り返りでは立ち上げ時の障壁が参加者44.4%、拠点37.0%、資金35.8%。**別地域の既存団体の調査**なので高岡の新規個人へ一般化しない。出典と比較は[需要・競合監査](DEMAND_AND_COMPETITOR_AUDIT.md)。

## 3. 対象の活動
- `child_place`：子どもの居場所・学習支援（重点の例。安全・責任体制の確認を優先）。
- `community_event`：非営利の体験会・交流ワークショップ（単発の初回開催も検討）。
- `other`：その他の非営利地域活動（一般的な確認と専門窓口への案内だけ）。
- **対象外**：店舗・営利創業、食事提供の衛生/許認可の判断、住宅・移住、空き家所有者向け診断。既存団体の管理業務・単なる参加先検索は扱わない。

## 4. 利用者に提供するもの（MVP）
| 価値 | できること | できないこと |
| --- | --- | --- |
| V1 今の障壁を見つける | 本人が「協力者/運営/会場/費用/何から始めるか」を選び、決まったことと未定事項を整理する | アプリが本人の本音や地域の不足を推測する |
| V2 **最初の事前確認カード** | 具体的な最初の一歩1件、補助行動最大2件。確認相手・質問・理由を表示 | 仲間・資金・施設を自動確保する |
| V3 高岡の実際の条件を確認 | 公式施設・相談窓口の出典、確認済みの利用上の注意、未確認点を示す | 申請の受理・予約・補助金の適格性を判定する |
| V4 相談の準備セット | 入力した活動条件と確認質問を下書きし、本人が確認してコピー | 勝手に送信・共有・データ蓄積する |
| V5 会場の選択肢を整理 | 既存施設／既存団体の拠点／必要なら空き家を確認事項で比較 | 個別の空き家や施設のリアルタイム空き情報を保証 |

**結果の最上部は「最初の一歩」**。施設・団体の検索結果ではない。

## 5. 入力（最小限）
**必須**：活動種類 `activityType`、現在の形態 `startingMode`（solo / forming_team）。
**任意**：最も困っていること `blocker`（people / operation / venue / cost / unsure / none_or_unknown）、協力者 `supportPeople`（available/looking/unknown）、活動責任者 `responsibleLead`（available/coordinating/unknown）、希望地区、日時・頻度、参加人数（整数/不明）、必要設備、活動説明（判断に使わない）。
**高岡市の地域交流センターをすでに検討している場合**：入力ステップ2で「高岡市地域交流センターを検討中か」（yes/no/unknown）を任意で聞く。yesのときだけ利用者構成（minor_only/adult_involved/unknown）を聞く。**正確な年齢や個人情報は不要**。結果の後から施設条件を変更した場合も、最初のカードと相談文を再計算する。
入力欄は子どもの実名、参加者の連絡先、実在の空き家の正確住所、GPSを収集しない。AI APIへの自由文送信なし。

## 6. 診断と結果の原則
- 見せるのは**必要な確認**。適合率、許認可、建物の安全、補助金採択、相談先の協力・施設利用の保証を出さない。
- 本人が選んだ障壁を尊重しつつ、子どもの安全と責任体制などの重要な注意を隠さない。
- 高岡市地域交流センターの**「未成年者のみで利用できない」**という2026年1月改定の公的注意を、当該センターを検討する人へ条件付きで表示する（全施設に一般化しない）。成人が関われば必ず許可されるという意味でもない。
- 公的サイトや相談窓口は既に存在する。本アプリはそれらを**置き換えず、相談に向けた準備を支援**する。
- 情報が未確認なら「未確認／公式窓口に確認」と表示。施設・制度の現況は要更新確認。

## 7. Must / Should / Later
**Must**：2段階入力、障壁・状況に応じた最優先アクション、地域の出典付き事前注意、相談質問とコピー文章、既存会場の確認方法、子どもの安全注意、操作とプライバシーの品質、決定的ルール。
**Should**：相談用文章の印刷、公式窓口への入口の拡充、選択した最初の行動の変更。
**Later**：実施設予約、空き家の物件検索、協力者マッチング、助成金の自動適格性判定、DB/アカウント、AI API。

## 8. 実装の可否を決める条件
**未実施の利用者検証が先**。実際に困った個人・小規模チームからエピソードを集め、自治体Web/検索/汎用AIと紙の回答カードを比較する。独自性が確認できなければ改善・方向転換。方法は[検証プロトコル](VALIDATION_PROTOCOL_V31.md)。
