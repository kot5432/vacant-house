# STEP7-⑧｜主要ブラウザ互換性の検証行列・技術課題 v0.1

**正式採用済み**：[ADR-014](ADR_014_MAJOR_DESKTOP_MOBILE_BROWSER_SUPPORT.md)により、PC・スマホの現行主要Chrome、Edge、Safari、Firefoxを検証対象とする。**本書の技術細部・最低バージョンは提案・未承認。実行試験は未実施。** 現行地域イベント準備支援Webアプリのみ。旧空き家案は対象外。

## 2. UnicodeとIMEの受け入れ契約

- 100/500字上限の`字`は書記素単位を第一候補。全対象ブラウザで同一入力に対する表示カウンターと保存検証が一致するかを検証。
- 文字ケース：ひらがな、濁点の結合表現、サロゲートペア、肌色修飾絵文字、ZWJによる絵文字連結、改行、半角・全角スペース、巨大な単一書記素。
- IMEケース：かな入力、漢字変換中、変換候補変更、キャンセル、連続入力、途中で上限に達する場合、確定後のエラー、スマホ予測変換。
- **`InputEvent.isComposing`単独で判定しない**。compositionイベントやUI入力状態との整合を実ブラウザで確認する。
- `Intl.Segmenter`の不存在時に黙ってUTF-16方式に変えない。対象版の機能有無を検証し、同一書記素計測の代替実装か非対応案内を設計。
- バイト長・表示長・保存長の上限を混同しない。巨大な1書記素に対する別の保護値は未承認。

## 3. IndexedDBと複数タブ

- U02入力途中はDB保存なし。初回プランの確定DB保存成功後のみU03に進む。
- U03進捗は自動保存。ただし成功前に成功表示しない。
- U04ドラフトは明示保存、キャンセル／容量不足／revision競合で旧イベントを保護。
- 異なるブラウザ／オリジン／端末は別の保存領域。バックアップ・同期は未採用。サイトデータ消去やプライベートモードでデータが失われ得る。
- 新版によるDexie upgradeで旧タブが`versionchange`を受ける場合に、既存データを誤上書きしない。サポート不可能なschemaVersionを初期化しない。

## 4. buildId／月末の公式出典

- 起動時・タブ復帰時に同一オリジンの軽量buildId確認（ADR-013）。新版照合成功で通知、**自動再読込しない**。
- 期限切れ出典の表示停止は、新版確認と別で、現在の静的カタログとJST評価日から判定（ADR-010〜012）。オフライン・古いタブ・端末時刻ずれによる完全保証なし。
- U02/U04の入力途中、U03の進捗保存中に更新を検知しても入力を消さない。ブラウザ側の強制終了などまで保証しない。

## 6. さらに必要な設計

- サポートバージョンと実機試験マトリクスの最終版
