# STEP2-⑯-①｜アンケート回答の保管期間 C案を採用（2026-11-21）

## ユーザー決定
- **C案「開発・検証が終わるまで回答データを保管する」**を採用。
- 保管の目的は富山県プログラミングコンテスト応募作品の需要検証、アプリの改善と評価に限る。
- **具体的な削除期限は未決定**。配布前に「開発・検証の終了条件」「具体的な最終削除日」「必要なら延期を判断する方法」を決め、回答者向け説明へ明記する。C案を無期限保管の許可とは解釈しない。
- E本人が個人Googleアカウントでフォーム・回答データを管理する（STEP2-⑭・⑮）。他メンバーに共有するのは原則匿名集計・要約のみ。

## 保管と削除の実行設計（提案・未実施）
1. Googleフォームの回答タブ、連携先Googleスプレッドシート、ダウンロードしたCSV/XLSX等の**全コピー**を管理対象として台帳化。
2. 回答者の氏名・メールアドレスは収集しない。自由記述欄に個人や団体の非公開情報を記載しないよう告知する。
3. 閲覧・編集権限はE中心の必要最小限。共有ドライブ、公開URL、GitHubへの生回答アップロードを避ける。
4. 開発・検証完了後、決めた期限までにフォームの回答・連携シート・ローカルコピー・ゴミ箱の保管を確認して削除する。匿名統計の継続利用可否は配布前の案内に記す。
5. 問い合わせ・回答撤回の運用（匿名で個別回答を特定できない場合の限界も含む）、調査ルール、未成年を含む任意参加を配布前に確認する。
