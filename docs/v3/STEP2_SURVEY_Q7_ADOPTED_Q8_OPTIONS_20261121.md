# STEP2｜アンケートQ7 A案採用・Q8検討（2026-11-21）

## 正式決定：Q7 困ったことを複数選択で聞く

- **質問**：「地域イベント・活動を探したり参加するか判断したりするとき、具体的にどのようなことで困りましたか？」
- **形式**：チェックボックス（複数選択）。
- **選択肢**：
  1. 自分に合うイベント・活動の情報が見つからなかった
  2. 開催日時・場所が分からなかった
  3. 対象年齢・参加条件が分からなかった
  4. 参加費が分からなかった
  5. 申込方法・申込期限が分からなかった
  6. 初参加でもよいか、一人で参加できるか分からなかった
  7. 情報が古く、現在も開催・募集しているか分からなかった
  8. その他
- **出し分け**：Q6で「よくあった」「ときどきあった」の人には表示する。「ほとんどなかった」の人への扱いはフォーム統合時に検討する。「まったくなかった」「自分で探した経験がない」「覚えていない・回答しない」の人には原則回答を強制しない。
- **目的**：参加D01の発見体験とD02の参加判断に必要な情報を区別し、実際の不便を把握する。
- **注意**：Q7の回答だけで新規フィルター採用を決めない。現行MVPのD01検索軸は地域・活動分野であり、日時・費用・対象年齢等はD02の確認情報。誘導的な「便利だと思いますか」は含めない。

## 次の検討：Q8（未決定）

**目的**：回答者が実際にどこからイベント情報を得ているか、既存手段の利用状況を把握する。

- **A案（推奨）**：「地域イベント・活動について、これまでどこで情報を見つけたり調べたりしましたか？」（複数選択：Instagram/XなどSNS／学校・職場などの案内／家族・友人・知人／自治体公式サイト・広報／主催団体・施設の公式サイト／イベント情報サイト・アプリ／チラシ・ポスター／その他／自分で調べたことはない／覚えていない・回答しない）。後ろ2つは他の項目と排他的に扱う。発見と能動的検索は厳密には異なるため、最終文言で調整する。
- **B案**：一番よく使う情報源を1つだけ選ぶ。主経路は分かるが併用を把握できない。
- **C案**：情報源の設問は省き、見つからなかった場合の行動（問い合わせ・参加見送りなど）を先に聞く。参加障壁は分かるが既存サービスとの接点を把握しづらい。
