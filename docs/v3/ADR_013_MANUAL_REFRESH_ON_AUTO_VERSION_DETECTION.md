# ADR-013｜旧タブはビルド識別子で新版を自動確認・再読み込みは本人操作（A案正式採用）

決定日：2026-11-15。ユーザーがA案を明示採用。**実装・動作試験・Vercel公開は未実施**。現行プロダクトは初めて単発・小規模の地域イベントを主催する人の「準備の全体像と優先順位」支援Webアプリ。旧空き家・所有者診断・物件・マッチング案を一切継承しない。

## 1. 正式決定
- アプリが開いている版の`buildId`と、**同一オリジンの軽量なビルド識別子**を起動時・画面復帰時などに自動照合する。照合できて**異なると判定したときのみ**新版の存在を通知する。
- **自動リロードしない**。再読み込みは本人の明示操作に限定する。更新が見つかってもU02初回入力（非永続下書き）、U04ドラフト、U03未完了の自動保存を破棄しない。
- 比較に使う識別子は**公式出典カタログの本文とは別の軽量な版識別子のみ**。公式出典カタログの実行時別配信・専用APIは[ADR-012](ADR_012_BUNDLED_OFFICIAL_SOURCE_CATALOG.md)で不採用。EventRecordの入力・進捗はバージョン確認先へ送信しない。
- 識別子取得失敗、タイムアウト、不正データ、キャッシュから旧識別子を返されたとき、**最新版がある／ないと断定しない**。現在の同梱出典の有効期限は[ADR-011](ADR_011_MONTH_END_SOURCE_REVIEW_DEADLINE.md)どおり独立評価し、失効なら個別施設の断定を停止する。
- 新ビルドを本人が読み込んだ後だけ、現行公式出典の最新版とルールを適用。本人のタスク進捗を無条件にリセットしない。

## 2. 入力・保存状態に応じた操作契約

| 画面・状態 | 新版検知時 | 再読込の本人操作 |
|---|---|---|
| U01閲覧・保存処理なし | 更新通知を表示 | 本人が再読み込みを選択したときのみ実行 |
| U02基本6問の入力途中 | 通知のみ。入力はReact内に保持 | 再読込すると未完成の入力が失われるため、**明確な確認を経た本人の選択**を必要とする |
| U03進捗保存中 | 通知のみ、保存完了前に再読込禁止 | 保存結果を確認後に再読込。失敗中は未保存変更を説明 |
| U04編集差分あり | 通知のみ。元の保存済み版とドラフトを維持 | 反映保存／破棄の本人操作を案内。ドラフトが残る間は強制再読込しない |
| U04変更保存失敗・revision競合 | 通知のみ。自動上書き・再読込なし | 保存状態・他タブの最新版と更新版の両方に注意。ユーザーが明示的に処理を選択 |
| 識別子の取得失敗 | 断定通知をしない | 手動再読み込みは別操作として利用可能（ただし未保存警告を守る） |

## 3. 実装前の補助技術設計（提案であり未採用の細目）
- 同一オリジンの静的`build-meta`ファイルには`buildId`だけを持たせ、配信時にキャッシュ方針を明記。プレビューと本番の識別子・保存領域を混同しない。
- 起動時・画面復帰時・U03を開いたときにチェックする案。確認頻度、キャッシュ無効化、タイムアウト、`buildId`の生成方式、ダウンロード失敗への表示方針は実装前に決める。
- 版チェックそのものは**現行の有効状態評価の代替ではない**。アプリを開いたままJST月末を越える場合、U03の公式出典を再評価する仕組みを別に用意する。
- 自動リロードを抑止するだけで**ブラウザ自身の再読み込み・クラッシュ・外部タブ操作によるデータ損失を完全に防ぐ保証はない**。
- 「最新版があります」表示は照合成功時だけ。古いコードが新しい`schemaVersion`のレコードを読めない場合に上書きしないことは、別途移行設計の重要事項。

## 4. 受け入れ試験（設計のみ、未実行）
| ID | 条件 | 期待 |
|---|---|---|
| VER-01 | buildId一致 | 更新通知なし |
| VER-02 | buildId不一致 | 更新通知。**自動再読込なし** |
| VER-03 | 通信エラー／タイムアウト／破損 | 新版ありと断定しない |
| VER-04 | U02の入力途中に不一致 | 入力保持。再読込の損失を本人へ確認 |
| VER-05 | U04に未保存差分あり | 自動再読込なし、保存または破棄の案内 |
| VER-06 | U03の進捗保存中 | 保存完了確認までは再読込しない |
| VER-07 | 更新版読込 | 同梱カタログ・本人条件・JST期限を再評価 |
| VER-08 | 旧ビルドが月末を越えた | 新版チェックに依存せず、旧カタログの出典断定を期限切れなら停止 |
| VER-09 | 別オリジンのPreview／本番 | 相互のバージョンとIndexedDBを混同しない |
| VER-10 | 削除済みイベントを保持する旧タブ | 新版確認でもイベントを復活させない |

**未決**：ビルド識別子の生成・配信ファイル形式／キャッシュ制御／検査頻度、アプリの再表示時刻の取得方法、未保存入力の警告文言とブラウザの保証範囲、スキーマ変更時の移行方法。これらの比較はSTEP7の後続設計へ。
