# 独自性を強める製品差分 v3.1 — 地域活動の事前確認ナビ
記録：2026-11-12／設計案。**プロトタイプ・コード・利用者検証は未実施**。

## 1. 新しい説明
旧：「地域活動の準備を整理し、次の一歩を示す」
**改善後：「始めたい活動の今の障壁を特定し、地域の実際の確認条件に沿って、最初に『誰に何を聞くか』を決める」**。
これは施設や制度の**利用適格性の自動判定ではない**。

## 2. 具体的なアウトプット（必須）
1. **現在の障壁の見取り図**：本人の選択に基づく「協力者」「運営責任者」「日時/人数」「会場」「資金」「どこで止まったか分からない」。未入力を勝手に問題と断定しない。
2. **最初の確認カード1件**：何が未確認／なぜ今これを確認／まず何をする／誰に確認／参照する高岡市の公式資料（ない場合は一般的な確認）／注意。
3. **次の確認事項最大2件**：異なる障壁に関する具体的な選択肢。必要な安全上の注意は別枠。
4. **相談の準備セット**：活動の概要、日時/人数の目安、未確定点、公式窓口へ確認したい質問を短文に整理。コピー可能、自動送信しない。
5. **場所を検討する際の分岐**：既存の公共施設→既存団体の拠点等→必要なら空き家。具体的な空室・利用可能物件を検索・保証しない。

## 3. 追加する最低限の質問
### Q：今、最も困っているのは？（任意、1つ）
- 相談・協力してくれる人がいない（people）
- 運営や責任をどうするか分からない（operation）
- 場所や設備をどう確保するか分からない（venue）
- 費用・資金について分からない（cost）
- 何を優先するか分からない（unsure）
- 特に困っていない／今は決まっていない（none_or_unknown）

**本人が困っていることを優先するが、安全・活動責任者の重要確認は上書きして隠さない。** 「資金が足りない」と選んでも、資金提供や補助金採択をできると表示しない。

### Q：地域交流センターを使う予定がある場合、利用する人は？
「未成年者のみ／成人が関わる／まだ決まっていない」。**個人の具体的年齢を収集しない**。
- 未成年者のみ→R8.1利用上の注意に沿って「この条件ではセンターは利用できない旨が掲載されている」と表示し、学校/保護者/信頼できる成人/センター管理者に確認する案内。
- 成人が関わる→それだけで許可済みとはしない。管理者による承認・用途など追加条件の確認を案内。
- 不明→状態を決める/管理者へ相談する。利用可と判断しない。
※これは特定施設の条件を扱う**確認ナビ**であり、ユーザーの法的地位や全施設への適合性を判断するものではない。

## 4. 出力例（架空の利用者）
**利用者**：「高校生3人で、子ども向けプログラミング体験会をやりたい。開催場所が見つからない」
- 既に決まっている：活動、3人の企画チーム、子ども向け。
- 今の障壁：会場。
- **最初に確認**：「高岡市地域交流センターの利用条件。未成年者だけでは利用できないと公式案内にあるため、学校・保護者・信頼できる成人や施設管理者に、必要な体制と手続を相談する。」
- **続く確認**：「参加人数・必要な電源/机/通信環境を整理」「受入れ可能な活動内容と希望日時を施設へ確認」。
- 参考：高岡市の公式センター案内と2026年1月改定利用上の注意。
- **言ってはいけないこと**：「成人がつけば必ず借りられる」「近隣空き家なら許可なしにできる」。
- 相談下書き：「学生3名で子ども向けの体験会を検討しています。未成年者のみでの利用に制限があると読みました。必要な責任体制、予約条件、活動内容と設備について確認したいです。」

## 5. 出力例（架空の利用者）
**利用者**：「成人を含む4人で地域交流会。責任者は決まったが、会場条件が分からない」
- 最優先：参加人数・開催曜日・必要設備をまとめ、希望する施設の利用可能な活動と申込方法を管理者に確認する。
- 追加：利用料・対象区域・利用条件は未確認と表示する。空き家は比較の最後の選択肢に留める。

## 6. 既存サービスとの関係
公式情報と相談窓口**そのものは代替しない**。本アプリは面談・予約前の**確認漏れを減らすための整理道具**。公的サイトに入力内容を送信・申請はしない。
汎用AIでも近いことは可能。違いを「すべての情報が正確」「地域初」と主張せず、**限られた確認済みルールと引用元・未確認表示、結果の再現性**で検証する。

## 7. MVPに追加するが増やさないもの
**追加（小さい）**：障壁の選択1問、条件の注意カード、相談文への確認質問反映。**追加しない**：施設の実空き検索、参加者集客、仲間探しマッチング、リアルタイム行政データ連携、助成金の適格判定、法令適合や安全認定、空き家の実物件照合。
