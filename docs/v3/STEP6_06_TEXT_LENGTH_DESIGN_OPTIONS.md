# STEP6-⑥｜任意メモの文字数制限・Unicode・保存の比較（2026-11-15）

> **状態：100字／500字のA案は[ADR-008](ADR_008_OPTIONAL_TEXT_LIMITS.md)で正式採用済み。Unicode書記素の計測と技術上限は実装前確認事項。** 技術はADR-001、初回下書きA、生成後保存B、施設情報削除ADR-005、過去日ADR-006、人数ADR-007が正式採用済み。旧空き家の物件データとは無関係。**実装・動作試験なし**。

## 1. 値の上限候補（いずれも任意入力であり空欄は有効）

| 案 | `venueNameMemo`（施設名メモ） | `optionalDescription`（イベントの説明） | トレードオフ |
|---|---:|---:|---|
| **A（推奨）** | 100字 | 500字 | 短めで画面が読みやすく、保存負担が小さい。説明を多く書きたい場合は足りないことがある |
| B | 200字 | 1,000字 | 詳しく書ける。長文表示と画面上での確認の負担が増える |
| C | 固定の上限なし | 固定の上限なし | 文字数エラーがなくなるが、極端な長文の性能・保存容量・表示の確認が必要 |

いずれも`venueNameMemo`は本人の任意メモであり公式施設名の検索・判定根拠として扱わない。`optionalDescription`の内容をAI解析して施設の条件を推定しない。

## 2. 文字数をどの単位で数えるか（推奨案）

**推奨：Unicodeの書記素クラスタ（grapheme cluster）**を基準に、見た目の1文字に近い表示を行う。例えば絵文字や結合文字が複数のUnicodeコードポイントを含むときでも、ユーザーにとって「1文字」と見える場合にカウンターと検証が一致しやすい。ただし、対応ブラウザと`Intl.Segmenter`の動作互換性を調査・試験してから最終確定する。

代替：
- Unicodeコードポイント：`Array.from(text).length`に対応しやすい。結合文字・絵文字シーケンスを複数文字と数える。
- JavaScript UTF-16コード単位：`text.length`で簡単だが、補助文字を2文字と数えるためユーザー向けの字数表示とずれやすい。

**技術的な追加注意**：書記素数上限だけでは巨大な単一書記素（大量の結合記号）を排除できない。安全性とブラウザ容量のため、UTF-8バイト数など**別の技術上限**と異常入力テストを設ける必要がある。上限値は既存のMVPの仕様と矛盾しない形で後続に決める。

## 3. 入力・表示・保存の提案仕様

1. 空欄は有効。未回答と「情報がない」との区別は画面ごとの任意欄の仕様に従う。
2. 日本語のIME変換中は`maxLength`などによる**強制切り捨てを避ける**。確定後に検証し、超過している場合は「◯字以内にしてください」と入力欄近くに明示する。
3. 文字数カウンターを常時・または入力中に表示（例：「86 / 100字」）。カウンターと保存前検証は同じ文字単位を使う。
4. 改行は画面内で保持し、画面に文字列として安全に表示。前後の空白を削除する場合も本人に分かる保存仕様にする。過剰な暗黙整形をしない。
5. HTMLに見える文字列を実行させず、本文テキストとして描画する。任意メモへの個人名・住所・電話・参加者名簿の入力は避けるよう案内。
6. **U04は「変更を反映する」まで保存しない**。上限超過ならドラフト内に保持し、保存の前にエラーと修正導線を表示。キャンセルで元のデータを保つ。
7. [ADR-005](ADR_005_CLEAR_INAPPLICABLE_FACILITY_INPUT.md)で施設固有データが非該当なら、U04確定保存成功時のみ施設名メモの該当値をクリア。画面中のドラフトと永続値を混同しない。

## 4. テスト候補（数値確定後）

| ID | ケース | 期待 |
|---|---|---|
| LEN-01 | 上限ちょうど | 保存可能 |
| LEN-02 | 上限+1文字 | 保存不可、文字数の説明を表示 |
| LEN-03 | 結合文字・絵文字 | 表示カウンターと保存検証の文字数一致 |
| LEN-04 | 日本語IME変換中 | 変換文字列を途中で切断しない |
| LEN-05 | 長い単一書記素 | 技術的なサイズ制限で保護し、性能問題を起こさない |
| LEN-06 | HTML風・改行あり | HTML実行なし、表示はテキスト |
| LEN-07 | U04保存失敗 | 編集中のメモは画面内に保持される |
| LEN-08 | U04キャンセル | 保存済み旧メモがそのまま残る |
| LEN-09 | 該当外になった施設メモ | ADR-005により保存成功時のみクリア |

## 5. 確認してほしい決定

**100字・500字のA案は[ADR-008](ADR_008_OPTIONAL_TEXT_LIMITS.md)で正式採用済み**。残りは「書記素数（推奨）／コードポイント数／UTF-16単位」の実装方式、Intl.Segmenter非対応ブラウザの扱い、技術バイト上限。

上限値は正式仕様に反映する。Unicode文字数・巨大な結合文字への対応と公式出典の更新頻度は別の技術・運用判断ゲート。
