## 3. Googleフォームの画面順・分岐（設定用）

Googleフォーム標準の「回答に応じてセクションに移動」は**ラジオボタン（選択式）・プルダウン**のみで利用できる。チェックボックスで枝分かれできない。したがってQ4を主催側の直前に移動する（番号自体は維持）。

| セクション | 質問順 | 進行先 |
|---|---|---|
| **S1 共通** | Q1 → Q2 → Q3-1 → Q3-2 → Q5 | S2へ |
| **S2 参加側の入口** | Q6（**このセクション最後の単一選択**） | よくあった/ときどきあった/ほとんどなかった→S3、まったくなかった/自分で探した経験がない/覚えていない・回答しない→S4 |
| **S3 参加側の経験詳細** | Q7 → Q9 | S4へ |
| **S4 情報源** | Q8 | S5へ |
| **S5 主催経験・関心** | Q4（**このセクション最後の単一選択**） | 開催した／準備した／開催を考えた→S6、考えたことはない/回答しない→**フォーム送信** |
| **S6 主催側** | Q10 → Q11 → Q12（**このセクション最後の単一選択**） | 一部足りなかった/ほとんど得られなかった→S7、それ以外→**フォーム送信** |
| **S7 不足情報** | Q13（任意） | **フォーム送信** |

**分岐の動作確認**：回答を変更して戻った場合の表示、必須状態、セクション末尾の「次へ／フォームを送信」を実機プレビューでテストするまで完了扱いにしない。

## 4. 必須・任意の提案

- Q1/Q2/Q3-1/Q3-2/Q5/Q6/Q4：各々「回答しない／経験なし」等の選択肢を持たせた上で基本必須を提案。
- Q7/Q9/Q8/Q10/Q11/Q12：回答体験を短くするため**必須にしなくてもよい**。ただしQ12に回答しないとQ13の条件分岐が動かないため、Q12は回答しない選択肢を用意して必須にする案。
- Q13：任意。空欄送信可能。
- Q2/Q8/Q9/Q10/Q11の「該当なし」「回答しない」などの排他的意味を持つチェックボックス項目について、**Googleフォーム標準では選択肢ごとの排他を確実には強制できない**。全設問確定後の調整で、選択肢の文言注意書き（「他の選択肢と併用しないでください」）と矛盾回答の集計除外・未判定扱いを基本とし、必要なら複数質問への分割をユーザーに相談する。排他制御を実装したとは表示しない。

## 5. Googleフォーム作成手順（まだ実施していない）

1. Googleフォームで新規フォームを作成。タイトル・説明に、調査目的・任意性・用途・問い合わせ手段（チームで別途確定）を書く。
2. **設定**：メールアドレス収集オフ、ログイン必須の組織制限オフを目標に確認。回答1回制限はログイン要件を生む場合があるため設定しない方向。回答編集許可・結果サマリー公開・通知の各設定も確認し、公開集計を避ける。
3. S1〜S7を表の順番で作り、該当質問をコピーする。Q4は設問番号を保持したままQ8の後に配置する。
4. S2/Q6、S5/Q4、S6/Q12の単一選択質問で三点メニュー→「回答に応じてセクションに移動」を選択し、上表どおりに枝分かれさせる。
5. S3→S4、S4→S5、S7→送信をセクション末尾で設定。S6のQ12以外からS7へ進む設定を作らない。
6. 選択肢の「その他」を自由入力にする場合は個人情報の注意書きをつける。Q13は任意。
7. 参加経験あり/なし、検索の困りあり/なし、主催準備あり/なし、Q12不足あり/なしの**少なくとも8パターン**でプレビュー送信を確認。テスト回答と実回答を混ぜない。
8. フォーム配布前に保存先（Googleフォーム/回答連携先）、閲覧権限、データ保持・削除期間、学校/チームのルール、未成年を含む任意同意、責任者と問い合わせ窓口を確定する。個人情報を含む回答の外部公開はしない。
