# STEP2｜アンケートQ12 A案採用・Q13検討（2026-11-21）

## 正式決定：Q12 既存情報の充足度

- **質問**：「イベントの企画・準備に必要な情報は、既存のサイトや周囲の人への相談などで十分に得られましたか？」
- **形式**：単一選択
- **選択肢**：
  1. 十分に得られた
  2. おおむね得られた
  3. 一部足りなかった
  4. ほとんど得られなかった
  5. まだ実際に調べたり準備した経験がない
  6. 覚えていない・回答しない
- **目的**：既存の情報源が主催者にとって十分かどうか、肯定・否定両方の回答から確認する。アプリ需要があることを前提としない。
- **対象**：Q4で主催経験・準備経験がある人を中心に質問する。経験のない人に回答を強制しない。全体のフォーム分岐を最終調整する際には、未経験者向け選択肢と分岐を整合させる。
- **注意**：「必要な情報が得られた」と「準備を完了できた」は異なる。回答を主催成功や需要有無の直接証拠と解釈しない。

## 次の検討：Q13（未決定）

**目的**：主催準備において足りなかった情報を具体化し、P01〜P12の準備プランが補う価値の仮説を検証する。

- **A案（推奨）**：「イベントの企画・準備で、既存の情報だけでは分からなかったことがあれば教えてください。」（任意の短文自由記述）。Q12の「一部足りなかった／ほとんど得られなかった」を対象とし、具体的な不足・順序の迷いを誘導せず収集する。氏名・連絡先や団体内の非公開情報は記入しないよう案内する。
- **B案**：「不足していた情報は何ですか？」（複数選択：準備の全体像／優先順位／会場・施設／申請／安全／費用／周知／その他）。集計しやすいがQ10との重複が大きい。
- **C案**：Q13を省略して全体の最終確認へ進む。回答時間を短縮できるが、Q12の評価理由が分かりにくい。

**Q13は未確定**。ユーザーが採用案を決めた後に記録する。今後、全設問の重複・分岐・回答時間3〜5分・配布文・プライバシー設定を一括でレビューする。
