# 開発前の机上ウォークスルー — 5つの架空ケース
更新：2026-11-12。**実ユーザーによるテストではない。** これは画面文言と出力の整合を設計上でレビューするための期待例。ケース中の人物・利用希望はすべて架空。行政の利用許可・資金支援を実証したものではない。

## Case 1：高校生3人／子ども向け体験会／地域交流センターを検討
- 入力：`child_place`／`forming_team`／blocker=`venue`／責任者未定／センター検討yes／利用者構成=`minor_only`／希望日時未定
- **最初のカード**：高岡市の地域交流センターの公式利用上の注意では「未成年者のみで利用するとき」は利用許可できない。**学校・保護者・信頼できる成人と活動責任・見守り体制を相談し、センター管理者へ利用条件を確認する**。
- 次のカード：対象年齢・参加人数・日時・必要備品を整理する。
- 常時の注意：子どもの見守り・保護者への説明・安全について、信頼できる大人や既存団体と確認。
- 出典：`TK-CENTER-01`, `TK-CENTER-02`。
- NG：大人さえいれば必ず借りられる、子どもを学生だけで預かれる、他の全施設も未成年だけでは使えない。

## Case 2：地域交流の単発イベント／成人が関わるチーム／会場未定
- 入力：`community_event`／`forming_team`／責任者あり／blocker=`venue`／センター検討yes／利用者構成=`adult_involved`／人数=20／日時決定
- 最初のカード：**地域交流センターの承認・活動内容・利用条件を管理者へ確認**（初めての申込みは各センターに問い合わせ）。
- 次：必要な部屋・備品・費用等を施設側に確認。インターネット申込みを使うなら予約システム事前利用者登録を確認。
- 出典：`TK-CENTER-02`, `TK-CENTER-03`。
- NG：「成人がいるから利用許可済み」「ネット予約を押せば確定」。

## Case 3：一人で地域の交流活動を始めたい／協力者なし
- 入力：`community_event`／`solo`／blocker=`people`／協力者探し中／センター検討no／地区未定
- 最初のカード：**活動の目的・規模を短く整理し、既存の市民活動団体や高岡市の市民活動相談窓口で協力の可能性や相談方法を確認する**。
- 出典：`TK-CONSULT-01`, `TK-PORTAL-01`。
- NG：「登録すると協力者が見つかる」「この団体は受け入れる」。

## Case 4：一人で単発ワークショップ／資金が障壁
- 入力：`community_event`／`solo`／blocker=`cost`／責任者未定／センター検討no
- 最初のカード：まず必要な費用の大まかな項目を整理してから、**市の相談窓口で現在の支援制度の対象条件を確認する**。
- 注意：2026年度市民共創チャレンジ事業第2回は**申請期限経過**。個人の単発イベントは公表条件から、申請できる前提にしない。
- 出典：`TK-GRANT-01`, `TK-CONSULT-01`。
- NG：「20万円の補助金がもらえる」「今年の第2回募集に今から応募できる」。

## Case 5：地域外／その他の非営利活動／条件がほとんど未定
- 入力：`other`／`solo`／blocker=`unsure`／高岡市外／日時・人数・協力者不明
- 最初のカード：活動内容、希望する時期、必要な設備、関わる人の種類を整理する。
- 出典：一般的な準備事項。**高岡市の施設・助成条件をその地域の制度として適用しない**。
- NG：「あなたの地域のこのセンターを利用できます」、架空の行政窓口や許認可案内。

## 設計上の整合点
- Case 1だけはセンターの**具体的な公式制約**を見落とさないよう、子ども向け活動の一般的な安全上の注意と一緒に表示する。
- Case 2は「大人が関わる」を**利用許可と誤認しない**。
- Case 3と4は**本人が選んだ障壁**によって異なる行動を返す。
- Case 5は汎用案内に縮退し、根拠のない地域情報を示さない。
- この5件は**実行テストの合格数ではなく、仕様上の期待値**。回答の有用性・誤解しやすさは将来の利用者テストで確かめる。
