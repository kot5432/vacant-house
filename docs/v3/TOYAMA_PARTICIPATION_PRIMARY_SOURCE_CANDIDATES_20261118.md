## C. 1件を実掲載へ移すときのチェックシート
- [ ] 主催者・出典責任主体が公表されている
- [ ] **個別活動**について一次原ページが存在し、リンクを確認できる
- [ ] 活動名、開催地域、活動分野が資料に裏付けられる
- [ ] 日時（単発・期間・定期・不明）の種類を区別し、実在する年だけ使う
- [ ] 募集状況が公式ページで実際に確認されているか。不明なら`unknown`、終了なら`closed`
- [ ] 参加条件/費用/持ち物/初参加歓迎/一人参加等は根拠がなければ`unknown`
- [ ] 外部リンクや画像・原文の転載条件、著作権・個人情報の観点を確認
- [ ] 一次情報を人が確認した日とレビュー担当を記録
- [ ] 次回点検担当と停止条件を設定
- [ ] 2人目のレビュー・正式採用判断

**安全側フォールバック**：上記が満たせなければ、活動を無理に掲載せず既存の公的・団体サイトの案内先を表示する。手動の掲載審査を自動取得と呼ばない。
