# STEP 5｜画面構成と利用体験の設計（2026-11-13）
**前提：STEP 1→4の範囲内。設計文章のみで、UI画像・コード・利用者テストは未実施。**
設計上の最重要指標は「何をすればよいかが分かる」ことであり、空き家の図解や診断スコアではない。

## 画面構成（5画面・原則1画面1主操作）
```text
U01 ホーム
  → U02 活動を教える（活動種類・個人/チーム）
  → U03 今の困りごと・開催条件（人数/日時/責任者、特定施設の検討有無）
  → U04 結果：最初の一歩（根拠・公式条件・確認相手・質問）
      ├→ 任意で公式施設/支援情報の詳細を展開
      └→ U05 相談用の文章を確認してコピー
  ← どこからでも条件入力へ戻り、結果は再計算
```

## U01 ホーム
**見出し**：「地域でやりたいことを、最初の一歩へ。」
**補足**：「初めて地域活動を開く人が、自分に必要な確認と相談の準備を整理できるサービスです。」
**主操作**：「活動の準備を整理する」。
**注意**：「活動が開催できること、施設を借りられること、協力者が見つかることは保証しません。」

## U02 活動を教える（ステップ1/2）
- 必須「何を始めたい？」：子どもの居場所・学習支援／地域交流・ワークショップ／その他。
- 必須「誰と？」：一人／立ち上げ前の小規模チーム。
- 任意「活動内容をひとことで」：判定には使わず、相談文の素材としてのみ用いる。
- 主操作「次へ」。未選択時はエラーを項目近くに示し、入力を保持。

## U03 今の困りごと（ステップ2/2）
- 「今いちばん困っていること」：協力者/運営/会場/費用/順序不明/なし・未定。
- 「協力できる人」「活動責任者」の状況。
- 希望地区、人数、開催時期/曜日、頻度、必要設備（すべて任意、**不明可**）。
- **高岡市の地域交流センターをすでに検討？** はい/いいえ/未定。はいなら「未成年のみ/成人が関わる/未定」を任意で問う。正確な年齢は聞かない。
- 主操作「最初の一歩を見る」。必須以外で分からないことは未確認として表示。

## U04 結果（中心画面）
```text
[あなたの活動] 非営利の地域体験会
[今の困りごと] 会場が決まっていない

まずこれを確認
  相手：希望する施設の管理者等
  質問：この活動・人数・希望時間で利用可能か、条件と手続きは？
  最初の行動：活動条件をまとめ、公式案内と管理者への確認事項を整理
  理由：会場を探す際に必要な利用条件が未確認
  根拠：公式URL（該当があれば）／一般的な準備例ならその表示
  注意：掲載された条件 ≠ 個別の利用承認

[次の確認事項] 最大2件
[安全/運営上の注意] 子ども向けなら必ず別枠
[公式情報・施設選択肢を詳しく見る]（任意）
[相談文を作る]（主操作）
[条件を直す]（副操作）
```
**重要**：該当する公的条件（未成年のみの高岡市地域交流センター利用制限等）がある場合は見落とさない。公式条件であることと、今この人が使えるかは別。

## U05 相談用の文章を確認・コピー
- 相談先の種類（市民活動相談窓口/施設管理者/既存団体/その他）を選び、**本人の入力**に基づいた説明文を表示。
- 確認質問は最初の一歩に紐づける。人数・時期が未定なら未定と書き、推測して作らない。
- コピー前に編集・内容確認。自動送信・宛先の個人情報記入・ログインは不要。
- 入力変更時は元の状態と矛盾する古い相談文を使わない。再生成内容と本人が加えた自由文の扱いをUIで明示する。

## 実装時に守るUXの品質
- 主操作は画面に一つ。戻っても入力を保持。狭幅320pxで横はみ出しがない。
- 色以外でも状態を伝える。キーボードのみで入力・修正・コピーまで可能。
- エラー、リンク不達、公式情報の旧版化、入力が不明、地域外を分ける。
- 公式サイトのリンクは「詳しい案内を見る」であり、許可/予約を確定する操作ではない。
- 地図や空き家カードを主画面に目立たせず、必要な人が任意に確認する補助情報にする。
