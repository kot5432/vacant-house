## 4. UI・アクセシビリティの検証

- **優先度と進捗を混ぜない**：P1/P2/P3、本人の完了、本人対象外、ルール上非該当、要再確認、出典の有効／期限切れは文章でも区別する。
- **320px・200%表示**で理由と次の一歩が省略されない。キーボードで展開・進捗・保存・エラー復帰が可能。
- 保存成功・失敗は読み上げを含む明確なステータスで示す。**未保存U02/U04ドラフトを新版更新のため強制破棄しない**。
- JSONバックアップは「選択／保存済み／今回含まれない」の3件数を正しく表示。端末ダウンロードの成功をアプリが保証しない。
- 利用者によるヒアリングで、本人が「なぜこのタスクが先か」「次に何をするか」を具体的に説明できるかを**実際に観察する**。本チェック表の作成は検証ではない。
