# STEP 4｜入力・結果・地域情報・判断ルールの設計（2026-11-13）
**STEP1〜3に従う、実装前の論理設計。コード・テストは未作成。**
判断規則の詳細正本は[DECISION_RULES.md](DECISION_RULES.md)。本書は機能間の契約と受入例。

## 1. 入力→判断→結果
| 入力値 | 役割 | 不明時の扱い |
| --- | --- | --- |
| activityType：子どもの居場所/学習支援、非営利地域交流/ワークショップ、その他 | 活動固有の注意と質問を選ぶ | **必須**、その他は一般案内に縮退 |
| startingMode：個人/準備中の小規模チーム | 協力者・担当の案内の違いを作る | **必須** |
| blocker：人/運営責任/場所/費用/順序不明/不明 | 本人が「いま何で止まっているか」を尊重 | 一般的な準備の順序を提示 |
| supportPeople / responsibleLead | 人・責任体制の確認 | 推測せず「未確認」とする |
| district / participantCount / schedule / equipmentNeeds | 会場の申込前に整理すべき条件 | 未定も受け付け、確定したと偽らない |
| centerConsidered（**高岡市**地域交流センター） | 当該施設固有の利用上の注意を条件付きで適用 | 未検討なら施設固有の利用不可を断定しない |
| centerUserComposition：未成年のみ/成人が関わる/不明 | センターを検討している場合だけ使う | 年齢は収集しない。「成人あり」は許可ではない |
| optionalDescription | 相談文の素材（任意） | 内容から活動カテゴリ・法律を自動推定しない |

人数入力は正の整数か不明。0・負数・小数はエラー。参加する子どもの氏名や個人情報、実際の空き家所在地は求めない。

## 2. 最初の確認カードを作る規則
1. **本人が明示的に検討する高岡市地域交流センターの、該当する公式利用制限**を見落とさない。未成年者のみの利用不可は公式PDFの規定であり、**全公共施設への一括適用は禁止**。
2. 子ども向けの活動で責任体制が未定なら、運営責任・見守り等について学校/保護者/信頼できる成人や既存団体へ**相談する行動**を提示。開催可否の自動判断はしない。
3. 上記を残した上で、本人の障壁に答える。人/運営/会場/費用のどれに困るかで「何を誰に確認するか」を変える。
4. 参加人数や日時が不明なら、施設へ相談するための目安を整理する。
5. 地域の根拠がない場合は一般的な準備と確認方法へ縮退。

**優先カードは1件、補助2件まで。安全上の注意・公式の重大制約は非表示にせず別枠にも残す。** 同一条件・同一ルール版・同一公的データ版なら同じ結果。

## 3. 結果データの最低項目
`activitySummary`, `knownFields`, `unknownFields`, `primaryAction{question,firstAction,contactType,reason,sourceIds,cautions}`, `secondaryActions[]`, `safetyNotes[]`, `consultationDraft`, `ruleVersion`, `sourcesVersion`。
- 「確認した条件」を理由として表示する。`sourceIds`が空なら**一般的な準備の例**と明示。
- 公的ルールを見つけた場合は、**対象施設**・**出典/確認日**・**個別の許可判断は未確認**を一緒に表示。

## 4. 公開情報の範囲
- 公的根拠台帳：[OFFICIAL_SOURCE_REGISTER.md](OFFICIAL_SOURCE_REGISTER.md)。初期は高岡市地域交流センター、相談窓口、サポナビなどの確認できた範囲だけを使用。
- 高岡市地域交流センターの「未成年者のみ利用できない」規定（R8.1改定）は、指定の施設が明示された場合だけ参照。利用者に年齢の詳細は聞かない。
- 同センターの初回申込み問い合わせ、ネット申込みに利用者登録が必要という案内は公式情報。**予約可能性ではない**。
- 受付期間が終了した募集制度は「募集中」として薦めない。
- 情報が更新・削除されたら、確認できない断定を抑止し、管理者に再確認する一般的な案内へ。

## 5. 期待ケース（設計レビューの基準）
| ID | 状況 | 結果の最低要件 |
| --- | --- | --- |
| L1 | 学生のみ・高岡市センター希望・子ども向け体験会 | 利用制限の注意・必要な責任体制・問い合わせ先、出典あり |
| L2 | 成人が関わるチーム・同センター | 未成年のみの条件を機械的に当てはめず、承認・初回問い合わせ・設備を確認 |
| L3 | 一人・協力者不足 | 相談先・協力を求めるための質問を出す。仲間が見つかると断定しない |
| L4 | 一人・費用が障壁 | 費用項目・制度条件の確認。締切済み助成金を今申請できると扱わない |
| L5 | 高岡市外・その他/不明 | 高岡固有のルールを誤適用せず一般案内 |
| L6 | 入力修正（未成年のみ→成人関与） | 最初のカードと相談文が再計算され、古い条件を残さない |

これらは**期待出力の設計**であり、単体テストが合格したという意味ではない。

## 6. 安全とプライバシー
子どもの居場所・学習支援では責任者や見守り、安全・保護者連絡等を専門家/適切な成人と確認する。本人の許可なく第三者に自動連絡しない。外部AIへ入力を送信しない。公的サイトを開く場合の外部通信やホスティングの通信ログは公開時に別途説明する。
