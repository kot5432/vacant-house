# ADR-009｜公式出典の月次・毎リリース前点検（A案正式採用）

決定日：2026-11-15。**ユーザーが月1回＋毎リリース前のA案を明示採用**。現行の単発・小規模地域イベント準備支援アプリ専用。旧空き家／所有者／物件／マッチング案を含めない。設計上の決定であり、**実際の公式サイト照合・リリース・テスト・自動監視は未実施**。

## 決定
1. **毎月1回**、掲載中のすべての公式出典の原ページを直接開き、URL到達性、対象施設、対象者・利用条件、改定情報、アプリの説明の適切さを点検する。毎月の担当・実施日を作業計画に割り当てる。曜日や月初・月末の固定日は未決。
2. **毎回の本番リリース前**にも、掲載に利用する出典を点検する。月次点検をしたばかりでも省略しない。
3. **初回掲載前**に原ページと対象条件を確認し、異なるメンバーによるレビューを記録。未確認の資料は`verified`にしない。
4. **改定・リンク切れ・誤案内の疑いを把握した場合は次の点検日まで待たない**。`needs_review`／`suspended`に変更して、その出典に依存する断定案内を停止する運用とする。施設側からの連絡に対する「24時間以内」などの期限保証は設定しない。
5. 月次点検を期限までに完了できなかった出典は**未点検として明示し、内容の現行性を保証しない**。未点検が続いた場合の表示停止・猶予期間のしきい値は安全性・運用上の重要な残件であり別決定。
6. 対応施設・利用者条件が一致する`verified`出典だけを表示し、`needs_review/suspended/retired`は断定文の根拠にしない。元出典の文章・費用・利用可否・申請期限を勝手に生成しない。
7. 出典変更によりP08等の以前の確認前提が変わった場合だけ`needsRecheck`を検討し、進捗`completed/not_applicable`を勝手に上書きしない。本人の再確認解除はADR-004を維持。
8. **Vercelに同梱する静的情報の更新は、旧タブに即時反映される保証がない**。旧配信物の扱い、更新通知、公開後の再読み込み設計は実装前の技術ゲート。

## 作業の責任分担

| 役割 | 責務 | 現時点 |
|---|---|---|
| 出典点検担当 | 毎月・リリース前に元ページを照合し確認日を記録 | チーム内の具体的人員は未指定 |
| 別メンバーのレビュー担当 | 対象施設／適用範囲／表示文言の正確さを確認 | 未指定 |
| 公開担当 | 出典差分とタスク・テストを照合、Vercelプレビューと公開判断 | 未指定 |

月次点検が実際に動き続けるよう、各担当のバックアップ、欠席時の代行、点検記録の場所を**公開前に決定**する。自動化・通知機能は採用していない。

## 確認記録の必須要素（運用仕様案）

`sourceId, sourceRevision, originalUrl, facilityScope, ruleScope, checkedAt, reviewer, result, changedFields, affectedTaskIds, status, action`。発行元ページに記載されていない公開／改定日は作らない。台帳ファイルは[OFFICIAL_SOURCE_REGISTER.md](OFFICIAL_SOURCE_REGISTER.md)を起点とする。

## 受入テストの期待値（未実行）

| ID | 条件 | 期待 |
|---|---|---|
| CAD-01 | 掲載初回 | verified化より前にURL・対象条件・確認日・2人目レビューがある |
| CAD-02 | 1か月後の月次点検 | 出典ごとの点検日と結果を記録できる |
| CAD-03 | 月次直後のリリース | 毎リリース前の点検を省略しない |
| CAD-04 | リリースが数か月ない | 月次点検が継続される |
| CAD-05 | 施設条件変更を発見 | 次月まで待たず、needs_reviewまたはsuspendedとして判断する |
| CAD-06 | 出典が非verified | 個別の施設固有断定を表示しない |
| CAD-07 | 公式条件の変更で完了P08に影響 | P08の進捗を保持して再確認判定、無関係P01は保持 |
| CAD-08 | 旧ブラウザタブ | サーバー配信更新だけで即時停止済みと誤表示しない |
| CAD-09 | 点検担当不在 | 代行または未実施を記録し、点検済みと偽らない |
| CAD-10 | 登録URLが不明 | 実際の公式URLが分かるまで推測登録しない |

## 採用済み・未決
**確定**：月1回＋本番毎リリース前＋初回掲載前に原ページを検証し、変更・誤案内を見つけた場合は予定を待たず対応。
**未決**：月の何日、担当者、バックアップ担当、遅延の許容期間と掲載停止の自動基準、最新高岡市公式情報の事実確認、旧タブ対策など。
