# STEP2-⑯-③｜回答データの最終削除上限日 A案（2026-11-21）

## 正式決定
- ユーザーは**A案「2027年5月31日を最終削除上限日」**を採用。
- 既決の「アプリ開発・検証完了後30日以内に削除」と組み合わせる。
- **原回答データの削除期限は、（開発・検証完了日＋30日）と2027年5月31日の早い方**。
- 完了日の定義・実績はEが記録する。検証が長期化しても2027年5月31日までに原データを削除する。上限日を延長するなら、事前に管理・案内と同意の再検討が必要。既存回答を黙って期限延長しない。
- 対象：Googleフォームにある個別回答、回答の連携スプレッドシート、CSV等の複製、ローカルバックアップ。集計しても個人を識別し得る少人数の回答や自由記述引用は原データとして扱う。
- Eの個人Googleアカウントで管理。元回答はGitHubへ置かず、メンバーには原則として個人を特定しない集計のみ共有する。

## Googleフォームの実際の設定に使うチェックリスト

### フォームの基本設定
- タイトル：「富山県の地域イベントへの参加・企画に関するアンケート」
- 設問と選択肢・画面順：[Q1〜Q13統合版](STEP2_GOOGLE_FORM_FINAL_STRUCTURE_AND_BRANCHING_20261121.md)に準拠（Q3が2小問で計14小問）。
- 質問をシャッフルしない。クイズ設定はオフ。
- メールアドレス収集：「収集しない」を選択する。
- 回答を1回に制限：オフ（ログイン要件を避ける方針）。組織内限定/回答者制限が意図せず有効になっていないことを確認。
- 回答の概要・グラフを回答者へ公開しない。回答後の編集を許すかは運用を決めてから設定。
- 編集者と回答先スプレッドシートの権限は原則Eのみ。連携シートを使うかはEの管理方針に沿って選ぶ。
- **まだ作成・設定したとは扱わない**。Googleフォームは公開前にプレビューでき、公開・回答者リンク配布は別の操作。

### 7セクションの順序と遷移
1. **共通S1** Q1→Q2→Q3-1→Q3-2→Q5 →S2
2. **参加の検索課題S2** Q6（単一選択・最後の質問）：
   - よくあった/ときどきあった/ほとんどなかった→S3
   - まったくなかった/自分で探した経験がない/覚えていない・回答しない→S4
3. **参加の困りごとS3** Q7→Q9→S4。Q7/Q9を必須にしない運用を優先。
4. **情報源S4** Q8→S5。
5. **主催経験S5** Q4（単一選択・最後の質問）：
   - 主な担当として開催/企画・準備した/開催を考えた→S6
   - 企画・開催を考えたことがない/回答しない→フォーム送信
6. **主催の困りごとS6** Q10→Q11→Q12（単一選択・最後の質問）：
   - 一部足りなかった/ほとんど得られなかった→S7
   - その他→フォーム送信
7. **不足情報S7** Q13（任意の短文自由記述）→フォーム送信

分岐はGoogleフォームの単一選択/プルダウンの「回答に応じてセクションに移動」で設定し、チェックボックスには設定しない。Q4の番号は変えず、表示位置だけS5に移す。
