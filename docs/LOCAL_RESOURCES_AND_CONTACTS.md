# 高岡市の既存資源・相談先の事前調査
確認日：2026-11-12。**公式Web掲載の確認に限る**。連絡・協力依頼・利用状況調査・現地確認はしていない。
この資料は、空き家を使う前に「地域に既存の活動・相談・制度があるか」を確かめるための一次調査。掲載をもって協力・支援・制度適用が確定したものとはしない。

## 1. 博労・川原の既存交流拠点（公式施設ページで確認）
出典：[高岡市 地域交流センター](https://www.city.takaoka.toyama.jp/soshiki/kyosomachizukurika/3/5/2/10189.html)（ページ記載更新2024-04-11）
- **博労地域交流センター**：高岡市博労本町4番2号。
- **川原地域交流センター**：高岡市大町11番4号。
- 市の案内では地域交流センターは2024-04-01から市立公民館に設置。地域団体が運営し、利用時間は午前9時〜午後9時30分（変更・例外の可能性あり）。
- 利用申請は各センターの承認や所定の手続きが関わる。掲載施設は必ずしもすべての人・時間帯・活動内容で使用できるわけではない。
- **設計上の結論**：「地域交流の場が地区に存在しない」と言ってはいけない。必要なのは、**誰がどの時間帯にどんな活動を行いたいか、既存施設で対応できない理由は何か**の検証。
- これら2施設が地域調査票のQ3/Q4で回答される可能性はあるが、施設名や利用障壁を調査で確認せずに需要の代理変数として使用しない。
- センターの掲載住所は**公表された公共施設の情報**であり、空き家の実物件の住所や所有者情報ではない。

## 4. 次の調査で聞くべきこと
**地域交流センターの担当者または利用経験者への質問案**：
1. 施設を利用できる人・活動・時間帯に制約がありますか？
2. 実際に利用できない時間帯や活動内容はありますか？
3. 既存施設では対応できない地域の活動にはどんな例がありますか？
4. 空き家など別の小さな拠点が必要となる場合は何でしょうか？
5. 施設の確保より、運営する人・費用・広報が問題となる場合はありますか？

**所有者・建物関係者への質問案**：
1. 活用方法を決められない最初の理由は何でしょうか？
2. 建物設備と利用可能性が区別されている表示は理解できますか？
3. 6用途のうち検討したいものと避けたいものは何ですか？
4. 実際の相談前に確認しておくと役立つ情報は何ですか？

**専門家への質問案**：
1. 「基本3項目がそろっている」という分類が誤認を招きませんか？
2. 子どもが集まる用途／飲食用途／住宅用途で外してはいけない初期注意事項は何ですか？
3. 運営主体の見込みがない場合、利用用途の提案をどのように表現すると適切ですか？

## 5. 製品に取り入れる場合の条件
- 現段階のMVPでは**公式リンクは「参考情報・相談先を調べる」**として案内するだけ。申請可否・補助金額・法令上の適合・団体とのマッチングは自動判定しない。
- 地区が選択されても区域別補助の対象かは**公式の区域GISと要件を照合するまで判定しない**。
- 施設があることと、利用できることを区別。「既存施設あり」という事実だけで「地域ニーズなし」ともしない。
- データ更新日、URL、確認日を記録。サイトが変更された場合に古い案内を確定情報として表示しない。
