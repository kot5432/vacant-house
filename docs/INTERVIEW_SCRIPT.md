# 住民・所有者・活動団体・専門家への聞き取り台本案
更新：2026-11-12／**未実施**。正式な調査責任者と取扱方法、必要な同意・承認を確定するまで外部に依頼しない。

## 事前確認
- 1回15〜25分を目安（相手の希望を優先）。参加は任意、中断・回答拒否可能。
- なぜ聞くか、結果を何に使うか、個人が分からない範囲で集約することを案内する。
- 氏名、連絡先、具体物件の所在地を聞き取り記録に残す必要はない。録音・顔写真・実名引用は別の明示的な承諾がある場合のみ。
- 発表で団体の協力を明記する場合は別途許諾を得る。許諾なしに個別回答や所属を引用しない。
- 学校・団体のルール、参加者の年齢に関する必要な保護者等の手続きを事前確認する。成人の関係者への聞き取りを優先する。

## 共通の導入（読み上げ例）
「空き家をどのように活用できるか、地域の状況とあわせて検討するWebアプリを設計しています。実際に役立つものにしたいので、困っていることやアプリへの意見を伺いたいです。答えにくい質問は飛ばして構いません。お話を個人が分からない形で要約して使う場合があります。公開や記録の扱いは事前にご説明した範囲に限ります。」

## 対象別の質問
### A. 地域住民・利用者
1. この地域で「場所があればよい」と感じた具体的な場面はありますか。
2. すでに使っている公共施設・地域交流施設や活動はありますか。
3. 利用を諦めたことがあれば、その理由は時間、場所、費用、手続き、活動内容、人手など、どのようなものでしたか。
4. 建物の用途を検討するときに、地域についてどんな情報があると参考になりますか。
5. 既存施設の活用だけで十分な場合はどんな場合でしょうか。

### B. 空き家所有者・管理経験者
1. 活用を考える際、最初に分からないことは何でしょうか。
2. 住宅、地域交流、学習支援、食事支援、仕事場、店舗のどれに関心がありますか。避けたい用途はありますか。
3. 設備の「あり・なし・不明」を入力する形式は現実的ですか。
4. 「基本項目が確認できた」を「利用できる」「許可済み」と受け取りそうですか。
5. 次に相談する先や確認事項として、何を知りたいですか。

### C. 活動団体・地域交流センター等
1. どのような活動と利用者を想定していますか。
2. 活動場所に困ることはありますか。困る場合、時間・設備・定員・予約・距離など何が障壁ですか。
3. 場所があっても運営に必要な人材・費用・広報が足りないことはありますか。
4. 空き家を活用するなら、どんな条件や連携先が必要でしょうか。
5. 新たな拠点が既存施設を補完できるとしたら、どんな役割でしょうか。

### D. 建築・不動産・食品衛生等の専門家
1. 用途別の「基本3確認項目」という表示に誤解や見落としはありますか。
2. 子どもが集まる用途、飲食用途、店舗用途で必須の初期注意は何でしょうか。
3. 設備の有無と法令上の利用可能性を誤認させない文章はどんなものですか。
4. 所有者が次に確認すべき窓口・資料は何ですか。
5. 6用途の区分や注意事項に改善の余地はありますか。

## 終わりの確認
「今日の話をもとに、個人が分からない形で『必要な確認事項』を改善します。もし内容の引用が必要になった場合は別に確認します。何か補足したいことはありますか。」
