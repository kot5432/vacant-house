# 画面・操作仕様 v2.0：活動から始める
更新：2026-11-12／**設計のみ・画面実装なし**。詳細な文章ワイヤーフレームは[DETAILED_WIREFRAMES.md](DETAILED_WIREFRAMES.md)。旧所有者向けv1はGit履歴へ。

## 共通ルール
- 調査不明・未入力でも、一般的な確認方法を出す。施設未収録と検索済み0件は区別。
- 適合率・推奨1位・必ず借りられる・地域に必要・開業できる等は表示しない。
- 地域情報は実/参考/未調査/架空と、出典日付・収録範囲を分ける。
- 端末幅320pxから、キーボード、文字拡大、入力保持、見出しとエラーを確認する（実装後の試験は未実施）。
- 活動者本人が次に取れる一歩を示す。所有者の入力を求めない。

## U01 ホーム
- 見出し：「地域で始めたい活動、場所と準備から考えてみよう」
- 価値：「活動の内容・希望人数・時間などを入力して、場所の選択肢と次に取る行動を整理します。」
- 主操作「活動の準備を整理する」。副操作「架空の例で試す」。
- 注意：「利用可能な会場・空き家・許可を確約するサービスではありません。」

## U02 活動入力 1/2：やりたいこと
- 活動カテゴリ（community/study/meal/work/shop/other）を選択。選択は必須。その他も選べる。
- 活動内容の自由記述は任意で、AIが分析したふりをしない。
- 活動の開催経験/構想の進み具合は任意。
- 「次へ」「戻る」。カテゴリ未選択だけ入力エラー。

## U03 活動入力 2/2：条件と運営
- 希望地区（高岡市の博労/川原/戸出/その他/未定。任意）、想定人数（不明可）、単発/定期/未定、希望時間帯、必要設備（調理、トイレ、電源、机、通信など）、運営主体（いる/これから探す/不明）、費用感（任意）。
- 「分からない」を強制的な不適合にしない。
- 主操作「検討する場所と次の一歩を見る」、副操作「戻る」。
- 地図ピンや正確な住所は要求しない。

## U04 結果：活動条件と場所タイプ
上部に「あなたの活動の条件」の要約。未定・未確認を見える化。
**場所の候補の考え方**を並列に3カード表示：
1. **既存の公共・地域施設**：時間、利用条件、人数、設備、費用、申込方法を確認。
2. **空き家を活用する**：所有者の協力、現況、整備・費用、契約・安全・法令面の検証が必要。
3. **その他の会場**：民間貸会場・活動拠点など、利用条件・費用・空き状況を確認。
カードには「向いている/不向き」の自動断定ではなく**確認ポイント、最初の行動、データ状態、詳細を見る**を表示。場所タイプのスコアや順位を作らない。

## U05 場所タイプ詳細：次の具体的な行動
- 活動の目的と条件、場所タイプ固有の確認点。
- 最大3件の優先行動カード：**確認したいこと／最初の行動／確認方法・相手の種類／理由・根拠／注意点**。
- 安全・衛生・施設の規則などは3件上限とは別枠で保持。
- 公式施設情報を採用できる場合だけ出典付きでリンク・概要を表示。予約可否、料金、活動許可は未確認と明示。
- 「戻る」「ほかの場所タイプを見る」「入力を修正する」。

## U06 比較：既存施設と空き家等を比べる
- 2場所タイプを並べて比較。項目：確認する条件／まだ分からないこと／最初の一歩／専門的な注意。
- PCでは左右、スマホでは縦並び。同じ種類を2回選ばない。
- 「どちらが最適」と結論づけない。利用者が選択する。

## U07 行動のまとめ
- 気になる場所タイプと**次にできる具体的な行動**の要約（保存や実施完了チェックは不要）。
- 「どんな施設条件を確認するか」「どこへ相談する種類の話か」「何をまだ確認していないか」を短くまとめる。
- ユーザーが自分で調べる想定。メール送信・団体への紹介・予約等はしない。
- 「ほかの候補を見る」「入力を修正する」。

## 例外と縮退
| 状態 | 表示 |
| --- | --- |
| 希望地区未選択 | 地域固有の施設情報は付与しないが、3タイプの比較と一般行動は提示 |
| 参加人数や時間が不明 | 「人数・時間帯が決まったら施設の受入条件を確認」 |
| 施設データなし | 「施設データ未収録」。施設がないとは断言しない |
| 収録範囲の検索済み0件 | 「収録済みの範囲で該当なし」。存在しないとは断定しない |
| 空き家の物件データなし | 「空き家の具体的な候補は未検索」。利用条件や所有者の確認を案内 |
| 活動がmeal・shopで飲食を扱う | 食品衛生・相談先・安全面の確認を常時表示 |
| 学習支援・子ども対象の活動 | 子どもの安全と責任者の確認を常時表示 |
| 架空の例 | 画面全体と根拠の近くに「架空データ」と表示 |

## 検証条件
初めての利用者が、活動内容を入力し、空き家以外も検討できると理解し、最初の行動を一つ説明できるか。**実際の利用者試験は未実施。**
