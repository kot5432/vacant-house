# 実証データ受領後の判断手順 v1.0
更新：2026-11-12／**検証の手順書であり、実際の検証結果ではない。** 個人情報の原票は公開リポジトリに保存しない。

## 目的
公式CSV、住民アンケート、聞き取り、利用者テストの資料が集まったとき、何を採用し何を保留するかを、人によって変わらない手順で決定する。基本診断の6用途・希望分類A・設備確認Bは、地域調査の内容だけでは変更しない。

## 1. 受領時の共通チェック
1. **出所**：公式URL／調査の責任者／回答の募集方法／調査日時／資料版。
2. **権利・同意**：データのライセンス、回答者への説明、集計・発表・公開の許諾範囲。用途外利用はしない。
3. **個人情報**：氏名、個別住所、連絡先、少数セル、原文などの識別リスク。原票はGitHub・公開JSON・AIチャットへ渡さない。
4. **範囲**：対象地区、期間、設問、母数、施設カテゴリ、網羅範囲が分かるか。
5. **品質**：欠損、重複、誤記、質問の誘導、サンプルの偏り、座標異常。
6. **表現**：情報の出所と限界をユーザーに表示できるか。
7. **審査**：少なくとも作成者とは別の担当者が確認し、採否を記録する。

## 2. データ種別別の扱い
| 受領したもの | 採用できる場合 | 採用できない・不十分な場合 | 変えてよい表示 |
| --- | --- | --- | --- |
| 市の公共施設CSV | ライセンス・列・座標・収録範囲・更新日を検証 | 正確な位置がない施設は距離計算から除外。カテゴリ未網羅は「未収録」 | 周辺施設一覧と出典・直線距離のみ |
| 地区別人口統計 | 地区ID・基準日・出典を確認 | 地区の不整合は統合せず「比較不可」 | 人口の背景情報のみ。需要の推定には使わない |
| 住民アンケート | 匿名性、質問文、対象地区、母数、募集経路、用途への紐づけを確認 | 未調査、母数欠落、地区不一致は「参考／未調査」 | 地域との接点・次の確認質問。用途順位は変えない |
| 活動団体の聞き取り | 適切な同意・匿名化・内容確認 | 個人が識別される詳細・非公開希望の内容は掲載しない | 確認すべき運営課題、必要な調査 |
| 所有者の聞き取り | 意図と実際の入力負担、表示の誤認を確認 | 実物件住所や秘密情報は掲載しない | 入力UI・説明・用語 |
| 専門家の助言 | 対象分野・助言の範囲を記録 | 個別物件の安全・許認可の判断は無断で一般化しない | 注意文と相談先 |
| 初見テスト | 協力への同意、提示版、観察メモ、迷った箇所を記録 | サンプルが少ない結果を一般化しない | UI文言、情報の順序、説明 |

## 3. アンケートを診断分岐へ採用する決定木
1. 実調査か？ **いいえ** → demoかnot_surveyedとして扱う。**はい** → 2。
2. 対象の地区・設問・調査時期・母数・公開許諾が明確か？ **いいえ** → 利用は参考に限定、特定用途の分岐へ採用しない。**はい** → 3。
3. Q4の障壁はQ4bで用途と結びつくか、Q8の内容は人が再確認したか？ **いいえ** → 用途別でなく背景情報として表示。**はい** → 4。
4. 匿名公開でき、募集の偏りや少数回答の限界を表示できるか？ **いいえ** → 公開しない。**はい** → 調査回答者に限定した事実と次の質問を表示。
5. 結果が「需要が高い」「この用途が最適」「開業可能」などの表現になっていないか最終レビューする。

## 4. インプット別の状態
- **source_status**: verified / provisional / rejected / unavailable / demo
- **coverage_status**: complete_for_defined_scope / partial / unknown / out_of_scope
- **publication_status**: publishable_aggregate / internal_only / needs_consent / not_collected
- **decision**: adopt / adopt_with_caveat / hold / reject
数字の信頼性を根拠なく「高87点」等で表現せず、理由テキストを残す。

## 6. 想定例（架空）
- 調査「学習支援施設の時間が合わない」：対象地区・母数・用途対応・匿名公開を確認できれば「既存施設の開館時間を確認する」質問に反映。地区の総意としない。
- 調査「学習支援が必要」という自由記述が1件だけ：単独の地区需要に変換しない。確認が取れなければ内部参考に留める。
- 施設CSVに駅が存在しない：駅がないとは判定しない。鉄道駅データは「未収録」。
- 学校の近くで空き家が見つかった：近接という事実を提示しても、学習支援需要を推定しない。
